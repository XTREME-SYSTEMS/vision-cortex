## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that verifies and refreshes authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Define a GoogleConnector entity in Base44 to persist per-service connection state (service name, scope, token expiry, last_sync, status).
- Implement OAuth token validation and refresh logic using stored refresh tokens for each of the six Google services.
- For each service, perform a lightweight canary API call (Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata read, Tasks tasklists, Search Console sites.list) to confirm live authorization.
- Record health results and any scope gaps into the GoogleConnector entity and emit a consolidated status report.
- Wire the orchestrator into the Discover layer so connected services feed the intelligence pipeline; register a Vercel Cron heartbeat to re-validate tokens periodically.
- Surface a status dashboard component (<50 lines, lucide-react icons) showing green/amber/red per connector.

## Acceptance Criteria
All six Google services return a successful canary API response, GoogleConnector entity records status='connected' with valid non-expired tokens for each, the cron heartbeat re-validates without manual re-auth, and the dashboard shows all connectors green.
