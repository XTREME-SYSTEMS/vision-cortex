## Summary
Build a unified Google Workspace connector health-check and token-refresh function that validates and maintains active OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `verifyGoogleConnectors` in Deno/TypeScript that iterates over the six authorized Google services.
- Load stored OAuth credentials (access/refresh tokens) from the Supabase `google_connections` table for the current workspace account.
- For each service, perform a lightweight authenticated probe: Drive (files.list?pageSize=1), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets metadata on a known test sheet), Tasks (tasklists.list), Search Console (sites.list).
- If a probe returns 401/403, invoke the token refresh flow against Google's OAuth token endpoint using the stored refresh_token and persist the new access_token + expiry back to Supabase.
- Record a per-service status object (service, connected boolean, scope, last_checked, latency_ms, error) and upsert into a `connector_health` entity.
- Emit a DeepRun log entry documenting the check for replayability and surface an aggregate `all_healthy` flag.
- Return a structured report and mark the Layer 1 gap 'Core infrastructure connectors authorized' as satisfied when all six services report connected.

## Acceptance Criteria
Invoking verifyGoogleConnectors returns all_healthy=true with each of the six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) reporting connected=true, valid non-expired tokens persisted in Supabase, a connector_health record upserted, and a DeepRun log entry created.
