## Summary
Build a unified Google Workspace connector health-check and integration verification function that confirms all authorized core connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) are live and usable by the Discover layer.

## Steps
- Enumerate all authorized Google connectors from stored OAuth credentials (Drive, Calendar, Gmail, Sheets, Tasks, Search Console)
- For each connector, refresh the OAuth token if expired using the stored refresh_token and Google token endpoint
- Issue a lightweight read probe per service (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata on a canary sheet; Tasks: tasklists.list; Search Console: sites.list)
- Record status, latency, scope coverage, and any auth errors per connector into a Base44 ConnectorHealth entity
- Normalize results into a single integration manifest consumable by the Discover layer data-source registry
- Emit alerts to the system log for any connector returning non-200 or missing required scopes
- Persist a replayable DeepRun log entry documenting the verification run

## Acceptance Criteria
All six connectors return a 200 read probe with valid (refreshed) tokens and required scopes; a ConnectorHealth record is written for each with status='healthy'; the integration manifest lists all six as available to the Discover layer; a DeepRun log entry is persisted and any failing connector triggers a logged alert.
