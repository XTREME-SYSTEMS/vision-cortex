## Summary
Build a unified Google Workspace connector health-check and orchestration function that verifies and manages the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Create a Base44 backend function (Deno/TypeScript) named googleConnectorOrchestrator that centralizes OAuth token validation and refresh for all six Google services
- Load stored OAuth credentials/refresh tokens from Supabase (zero-credit store) for each connector
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) perform a lightweight liveness probe against its API and refresh expired access tokens
- Persist connector status, scopes, last-checked timestamp, and error details into a Base44 GoogleConnector entity
- Expose per-service capability metadata (available scopes and rate limits) to the Discover layer for intelligence gathering
- Emit a consolidated health report and surface any degraded connector to the Council/Understand layer
- Register the function on Vercel Cron heartbeat to re-validate connectors periodically
- Add structured logging to DeepRun for replayability of each validation run

## Acceptance Criteria
Invoking googleConnectorOrchestrator returns a status report showing all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) as 'connected' with valid, refreshed tokens; connector records are persisted in the GoogleConnector entity with recent last-checked timestamps; the cron heartbeat re-runs validation on schedule; and any failed connector is flagged with actionable error details in DeepRun logs.
