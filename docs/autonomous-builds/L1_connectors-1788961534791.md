## Summary
Build a unified Google Workspace connector health-check and token-refresh layer that verifies and maintains authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function 'googleConnectorHealthCheck' that iterates over the six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console)
- For each service, validate the stored OAuth token by performing a lightweight read call (e.g., Drive about.get, Calendar calendarList.list, Gmail profile.get, Sheets spreadsheets metadata, Tasks tasklists.list, Search Console sites.list)
- If a token is expired, invoke the OAuth refresh flow using the stored refresh_token and persist the new access_token/expiry into the Supabase 'google_credentials' store
- Record each service's status (connected/degraded/failed), last-checked timestamp, and granted scopes into a Base44 entity 'ConnectorStatus'
- Expose a single aggregated status payload and log the run to DeepRun for replayability
- Add a Vercel Cron heartbeat entry to call this function every 30 minutes for autonomous token maintenance
- Emit alerts to the Understand layer when any service is failed or scopes are insufficient

## Acceptance Criteria
Invoking googleConnectorHealthCheck returns a status object listing all six Google services with 'connected' state, valid non-expired tokens persisted in Supabase, a ConnectorStatus entity row updated per service, a DeepRun log entry created, and the Vercel Cron heartbeat scheduled and firing successfully.
