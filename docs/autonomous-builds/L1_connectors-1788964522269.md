## Summary
Build a unified Google Workspace connector service that verifies and persists authorized OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console into the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that accepts the target service list and performs OAuth token validation per service
- Store or refresh OAuth credentials in Supabase table `google_connections` (columns: service, scope, access_token, refresh_token, expires_at, status, last_verified)
- For each service, invoke a lightweight health-check API call (Drive: files.list limit=1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata ping; Tasks: tasklists.list; Search Console: sites.list) to confirm live authorization
- Map each verified connection into the Discover layer data-source registry so downstream Understand/Predict layers can consume it
- Record verification results as a DeepRun execution log entry with per-service status and timestamps
- Expose connection status via a Base44 entity `IntegrationStatus` for dashboard visibility
- Handle token refresh failures gracefully by flagging status='degraded' and emitting an alert intel item

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status='connected' in the `google_connections` Supabase table with a valid last_verified timestamp, each passes its live health-check API call, a corresponding DeepRun log entry is persisted, and the IntegrationStatus entity reflects the connected state on the dashboard.
