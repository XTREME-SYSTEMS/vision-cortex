## Summary
Build a unified Google Workspace connector service that validates and exposes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections to the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorHub` that centralizes OAuth token retrieval and refresh for all authorized Google services
- Register each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with its required scopes and API endpoint in a config map
- Implement token refresh logic using stored refresh tokens, persisting updated access tokens to Supabase for zero-credit reuse
- Add a per-service health-check probe (lightweight read call) that verifies each connection returns 200 and valid data
- Expose a normalized `getServiceClient(service)` accessor for downstream Discover-layer functions to call authenticated APIs
- Log connection status, last-verified timestamp, and scope coverage into a `IntegrationStatus` Base44 entity
- Wire the health checks into the Vercel Cron heartbeat so connectors are re-validated each autonomous loop
- Handle failure states by flagging degraded services and emitting a reconnect-required event

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return a successful health-check (200 + valid payload), token refresh works without manual re-auth, IntegrationStatus entity shows each service as 'connected' with a recent last-verified timestamp, and the cron heartbeat re-validates connectors each loop without errors.
