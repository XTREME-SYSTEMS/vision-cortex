## Summary
Build a unified Google Workspace connector service that verifies and manages authorized connections to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console within the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorManager` that centralizes OAuth token handling for all six Google services
- Store connector credentials and refresh tokens securely in Supabase (zero-credit external store) under a `google_connectors` table keyed by service and account
- Implement token refresh logic that auto-renews expiring OAuth tokens before each service call
- Add per-service health-check probes: Drive (files.list), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets metadata read), Tasks (tasklists.list), Search Console (sites.list)
- Expose a normalized connector status object reporting authorized/scopes/lastVerified for each service
- Wire connector outputs into the Discover layer data sources so downstream Understand/Predict layers can query them
- Log each verification run to DeepRun for replayability and register the spec in DeepSpec
- Emit alerts on any connector returning unauthorized or scope-mismatch

## Acceptance Criteria
Calling googleConnectorManager returns a status object where all six services (drive, calendar, gmail, sheets, tasks, searchConsole) report authorized=true with valid non-expired tokens and successful health-check probes; a DeepRun log entry is created and the connectors are queryable by the Discover layer.
