## Summary
Build a unified Google Workspace connector service that verifies, health-checks, and exposes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations to the Discover layer.

## Steps
- Create a Base44 backend function 'googleConnectorSync' that reads stored OAuth credentials for the Google Workspace account from Supabase
- Validate each scope token (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with a lightweight authenticated ping to each API's discovery/about endpoint
- Implement token refresh logic using the stored refresh_token, persisting new access tokens back to Supabase
- Record per-service connection status, granted scopes, and last-checked timestamp in a Base44 'IntegrationStatus' entity
- Expose normalized read helpers (listDriveFiles, listCalendarEvents, listGmailThreads, readSheet, listTasks, getالسsearch ConsoleQueries) so the Discover layer can consume Google data for zero-credit intel
- Register the function on Vercel Cron heartbeat to re-validate connectors every 6 hours and alert on any degraded/expired connector
- Log each sync run to DeepRun for replayability and audit

## Acceptance Criteria
Invoking googleConnectorSync returns status=connected for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with valid non-expired tokens, an IntegrationStatus entity row is written per service with a fresh last-checked timestamp, expired tokens are auto-refreshed, and each read helper returns live sample data without error; the cron re-validation runs on schedule and logs to DeepRun.
