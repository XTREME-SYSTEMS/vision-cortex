## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and normalizes all authorized Google service connections (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) into the Discover layer.

## Steps
- Create a Base44 backend function `syncGoogleConnectors` (Deno/TypeScript) that iterates over each authorized Google service using the @/ import alias.
- For each service, verify the stored OAuth token is valid and non-expired; refresh via the Google token endpoint if needed and persist updated tokens to the Supabase `google_connections` store (zero-credit operation).
- Define a normalized `ConnectorStatus` entity with fields: service, connected (bool), scopes[], lastSyncedAt, tokenExpiry, error (nullable).
- Perform a lightweight probe call per service (Drive: files.list?pageSize=1, Calendar: calendarList.list, Gmail: users.getProfile, Sheets: spreadsheets metadata, Tasks: tasklists.list, Search Console: sites.list) to confirm live access.
- Write each probe result into the ConnectorStatus records and surface them to the Discover layer data plane.
- Register the function on Vercel Cron heartbeat for periodic re-validation and log runs to DeepRun.
- Return an aggregate report indicating overall connector health and any services requiring re-authorization.

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return connected=true with valid non-expired tokens and successful probe calls; ConnectorStatus records are persisted in Supabase, a DeepRun log entry is created, and the aggregate report shows overall health as healthy with zero services flagged for re-authorization.
