## Summary
Build a unified Google Workspace connector health-check and orchestration function that verifies and registers authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors into the Discover layer.

## Steps
- Enumerate the six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and their required OAuth scopes.
- For each connector, validate stored OAuth credentials/refresh tokens against the Base44 integration store and refresh if expired.
- Perform a lightweight live probe per connector (e.g. Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live connectivity.
- Register each healthy connector as a Discover-layer data source in the connector registry with status, scopes, and last-verified timestamp.
- Persist a ConnectorHealth record per connector in Supabase for zero-credit auditing and expose aggregate status.
- Emit a DeepRun log entry summarizing connected vs failed connectors and surface remediation actions for any failures.

## Acceptance Criteria
Invoking the function returns a report where all six Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) show status 'connected' with a fresh last_verified timestamp, each has a corresponding ConnectorHealth record in Supabase, all are registered as Discover-layer data sources, and a DeepRun log confirms zero failed connectors.
