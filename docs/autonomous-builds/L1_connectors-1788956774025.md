## Summary
Build a unified Google Workspace connector service that validates and centralizes authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console for the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorManager` that centralizes OAuth token retrieval and refresh for all Google Workspace scopes
- Store connector credentials and scope grants in a Supabase table `google_connectors` (fields: service, status, scopes, token_expiry, last_verified)
- Implement per-service health-check calls: Drive files.list, Calendar events.list, Gmail users.getProfile, Sheets spreadsheets.get, Tasks tasklists.list, Search Console sites.list
- Normalize responses into a standard `ConnectorStatus` shape (service, connected boolean, scopes[], error)
- Wire connector outputs into the Discover layer data source registry so the Council/Intelligence Protocol can consume them
- Add token auto-refresh with retry/backoff and log results to DeepRun for replayability
- Expose a summary endpoint returning aggregate connection health for all six services

## Acceptance Criteria
Calling googleConnectorManager returns connected:true with valid non-expired scopes for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console); each health-check API returns HTTP 200; connector statuses persist to the google_connectors Supabase table; and the Discover layer registry lists all six as active data sources with a DeepRun log entry recorded.
