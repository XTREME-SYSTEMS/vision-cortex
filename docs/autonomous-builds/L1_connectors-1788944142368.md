## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that verifies and refreshes OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function that reads stored Google OAuth credentials for each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) from Supabase/Base44 entities.
- For each service, perform a lightweight authenticated ping (e.g. Drive files.list?pageSize=1, Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets.get on a health sheet, Tasks tasklists.list, Search Console sites.list) to verify the token is valid.
- Detect expired access tokens and refresh them using the stored refresh_token against Google's OAuth token endpoint; persist refreshed tokens back to the store.
- Record per-service connection status, last-checked timestamp, granted scopes, and any error into a GoogleConnector entity for observability in the Discover layer.
- Return an aggregated health report and expose it to the autonomous heartbeat (Vercel Cron) for periodic re-validation.
- Log the run to DeepRun for replayability and emit alerts on any service failure.

## Acceptance Criteria
Invoking googleWorkspaceConnectorSync returns status 'connected' for all six Google services with valid refreshed tokens, a GoogleConnector entity record is written with per-service status and timestamps, and a DeepRun log entry is created; any service that fails auth is flagged with an actionable error in the report.
