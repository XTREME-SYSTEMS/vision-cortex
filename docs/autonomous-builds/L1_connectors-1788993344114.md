## Summary
Build a unified Google Workspace connector health-check and normalization function that verifies and standardizes access to the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors.

## Steps
- Enumerate the authorized Google Workspace scopes (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) from the stored OAuth credentials in Supabase
- Implement a Deno/TypeScript backend function on Base44 that iterates each connector and issues a lightweight read probe (e.g. Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list)
- Normalize each probe result into a standard ConnectorStatus shape { connector, connected, scopes, lastChecked, error }
- Persist the results as a ConnectorHealth entity in Base44 and mirror to Supabase for zero-credit reads
- Trigger token refresh via the Google OAuth refresh endpoint for any connector returning 401/expired
- Expose the aggregated health map for the Discover layer to consume as data sources
- Wire a Vercel Cron heartbeat to invoke this function on a recurring interval for continuous monitoring

## Acceptance Criteria
Function returns a status map with all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) reporting connected:true with valid scopes, a ConnectorHealth record is persisted in Base44 and mirrored to Supabase, expired tokens are auto-refreshed, and the Vercel Cron successfully invokes the function on schedule without errors.
