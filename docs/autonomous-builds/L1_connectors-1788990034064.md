## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and normalizes access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` (Deno/TypeScript) that loads OAuth credentials for each authorized Google service from Supabase secrets.
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authenticated probe call to verify token validity and refresh expired tokens.
- Normalize probe results into a `ConnectorHealth` entity record with fields: service, status, scopes, last_synced, error.
- Persist connector metadata (available scopes, primary account email, quota state) into Supabase for zero-credit reads.
- Wire the function into Vercel Cron as a periodic heartbeat to keep tokens fresh and detect revoked access.
- Emit a consolidated status summary to CoreDocument/architecture Data Plane index and surface failures to the Council layer.
- Add retry-with-backoff and structured error logging using lucide-react-free JSX admin dashboard component for status display.

## Acceptance Criteria
Invoking googleConnectorSync returns a 200 with a health report listing all six Google services as status 'connected', ConnectorHealth records exist in Supabase with valid last_synced timestamps, expired tokens are automatically refreshed, and the Vercel Cron heartbeat runs the sync on schedule without credit-consuming errors.
