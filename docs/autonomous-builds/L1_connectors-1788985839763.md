## Summary
Build a unified Google Workspace connector health-verification and orchestration function that validates and registers the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors into the Discover layer.

## Steps
- Create a Base44 Deno/TypeScript backend function `syncGoogleConnectors` that iterates over the six authorized Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).
- For each service, retrieve stored OAuth credentials from Supabase and perform a lightweight read call to confirm token validity (e.g., Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list).
- Refresh any expired OAuth tokens using the stored refresh_token and persist updated access tokens back to Supabase.
- Upsert a `ConnectorStatus` Base44 entity record per service capturing {service, status, scopes, last_checked, latency_ms, error}.
- Register each healthy connector as an active Discover-layer data source so the Intelligence Gathering Protocol can consume it.
- Emit a consolidated health report and log the run to DeepRun for replayability.
- Schedule the function on Vercel Cron heartbeat to re-verify connectors periodically.

## Acceptance Criteria
Invoking syncGoogleConnectors returns status 'connected' for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), each has a fresh ConnectorStatus entity with last_checked within the run window, expired tokens are auto-refreshed, all healthy connectors appear as active Discover-layer data sources, and the run is logged to DeepRun.
