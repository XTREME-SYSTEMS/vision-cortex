## Summary
Build a unified Google Workspace connector service that validates and consolidates OAuth access across Drive, Calendar, Gmail, Sheets, Tasks, and Search Console into a single health-checked integration layer.

## Steps
- Create a Base44 backend function `googleConnectorManager` in Deno/TypeScript that centralizes Google OAuth token storage and refresh logic
- Define a `GoogleConnection` Base44 entity to persist per-service authorization status, scopes, token expiry, and last-verified timestamp
- Implement scope validation for each of the six services (drive.readonly/file, calendar, gmail.readonly, spreadsheets, tasks, webmasters.readonly)
- Add token refresh handling using the stored refresh_token, updating expiry on the entity
- Implement a `healthCheck` action that pings a lightweight read endpoint per service (e.g. Drive about.get, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list)
- Persist health results and surface a consolidated status object per connector
- Wire the connector into the Discover layer data sources per the Intelligence Gathering Protocol
- Register a Vercel cron trigger to re-verify connections and refresh tokens on a heartbeat interval

## Acceptance Criteria
Invoking googleConnectorManager with action=healthCheck returns a status object listing all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) each marked 'connected' with valid non-expired tokens; the GoogleConnection entity reflects a recent last-verified timestamp; and the cron heartbeat successfully refreshes tokens without manual re-auth.
