## Summary
Build a unified Google Workspace connector health-check and sync service that verifies and refreshes OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that accepts a list of Google service scopes to validate
- Load stored OAuth credentials from Supabase (external zero-credit store) for each Google Workspace service
- For each connector (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authenticated ping (e.g. Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list)
- Detect expired access tokens and refresh them using the stored refresh_token via the Google OAuth token endpoint
- Persist refreshed tokens and per-service connection status (connected/degraded/failed, last_checked_at, error) to a Supabase `google_connectors` table and mirror into a Base44 entity for app visibility
- Return a consolidated health report; emit a DeepRun log entry recording the check as a deterministic Act-layer execution
- Wire this function into a Vercel Cron heartbeat to re-validate connectors on a schedule and auto-heal expired tokens
- Surface connector status in the Discover-layer data sources UI using lucide-react icons per Technical Standards

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' in the consolidated health report, expired tokens are automatically refreshed and persisted to Supabase, a DeepRun log entry is created for the check, and the Vercel Cron job runs the validation on schedule without manual intervention.
