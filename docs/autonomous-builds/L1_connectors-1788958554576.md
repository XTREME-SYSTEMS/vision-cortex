## Summary
Build a unified Google Workspace connector health-check and integration registry that verifies and registers the six authorized Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) into the Discover layer.

## Steps
- Create a Base44 backend function that reads stored OAuth tokens for the Google Workspace account from Supabase secrets store
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authorized ping (e.g., Drive files.list?pageSize=1, Calendar calendarList.list, Gmail users.getProfile, Sheets metadata read, Tasks tasklists.list, Search Console sites.list)
- Record connection status, scopes granted, token expiry, and last-checked timestamp for each service into a ConnectorRegistry Base44 entity
- Refresh any expired access tokens using the stored refresh_token and update the secret store
- Emit a normalized health report and register each healthy connector as an available Discover-layer data source
- Log the run to DeepRun for replayability and surface failures with actionable remediation messages

## Acceptance Criteria
ConnectorRegistry contains six entries (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) each with status='connected', valid non-expired token, granted scopes listed, and last_checked timestamp within the last minute; a DeepRun log entry exists for the verification run and any failing connector reports a specific error and remediation step.
