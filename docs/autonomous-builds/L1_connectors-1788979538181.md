## Summary
Build a unified Google Workspace connector service that verifies, persists, and health-checks OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a GoogleConnection Base44 entity storing service name, OAuth token references, scopes, connection status, and last health-check timestamp for each of the six Google services
- Implement OAuth scope validation ensuring each service has the minimum required scopes (drive.readonly, calendar.readonly, gmail.readonly, spreadsheets, tasks, webmasters.readonly)
- Build a connector verification routine that makes a lightweight test API call per service (Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list)
- Persist connection results and health status to the GoogleConnection entity in Supabase for zero-credit reads
- Expose an aggregated status endpoint returning per-service connected/expired/error states for the Discover layer
- Schedule a Vercel Cron heartbeat to re-run health checks and refresh tokens before expiry
- Log all verification runs to DeepRun for replayability

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' from the aggregated status endpoint, each backed by a successful live test API call, GoogleConnection records are persisted with valid scopes and recent health-check timestamps, and the cron heartbeat successfully refreshes tokens without manual intervention.
