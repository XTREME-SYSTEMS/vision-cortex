## Summary
Build a unified Google Workspace connector service that validates and manages OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a GoogleConnector entity in Base44 to track each service's OAuth token, scopes, connection status, and last-validated timestamp
- Implement a backend function that performs OAuth token validation and refresh for each of the six Google services using stored credentials
- Verify required scopes per service (drive.readonly/file, calendar, gmail.readonly/send, spreadsheets, tasks, webmasters.readonly)
- For each service, execute a lightweight health-check API call (e.g. Drive about.get, Calendar calendarList.list, Gmail profile.get, Sheets metadata, Tasks tasklists.list, Search Console sites.list)
- Persist connection status and any errors back to the GoogleConnector entity in Supabase for zero-credit reads
- Expose a consolidated status object that the Discover layer can query for available data sources
- Register a Vercel cron heartbeat to re-validate and refresh tokens periodically to keep connectors alive

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return a healthy status from their health-check calls, GoogleConnector entities show connected=true with valid non-expired tokens, and the Discover layer can enumerate all connected sources; cron re-validation runs without errors.
