## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes OAuth tokens for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console, feeding the Discover layer.

## Steps
- Verify stored OAuth credentials exist for each Google service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) in Supabase secure credentials store
- Implement token refresh logic using the Google OAuth2 refresh_token grant, updating expiry timestamps in Supabase
- For each service, perform a lightweight authenticated ping (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata; Tasks: tasklists.list; Search Console: sites.list)
- Record connector status (connected/degraded/failed), scopes granted, and last_checked into a GoogleConnectorStatus Base44 entity
- Emit discovered data references into the Discover layer intake for downstream Understand/Predict processing
- Schedule the orchestrator on Vercel Cron heartbeat to re-validate connectors every 6 hours
- Surface a status summary to the system dashboard and log to DeepRun execution logs

## Acceptance Criteria
All six Google services return a successful authenticated ping with valid non-expired tokens, GoogleConnectorStatus entity shows status=connected for each with recent last_checked timestamp, the cron job runs without errors, and connector data references appear in the Discover layer intake.
