## Summary
Build a unified Google Workspace connector health-check and sync layer that validates and refreshes OAuth access for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function that reads stored Google OAuth credentials from the Supabase secrets/tokens store for each connected service.
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authenticated ping (e.g., Drive about.get, Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets metadata read, Tasks tasklists.list, Search Console sites.list).
- Detect expired or invalid tokens and automatically refresh them using the stored refresh_token via the Google OAuth token endpoint.
- Persist refreshed access tokens and updated expiry timestamps back to the secure token store.
- Write a ConnectorStatus record per service into the Base44 entity layer with fields: service, status, last_checked, scopes, error.
- Expose an aggregated health summary suitable for the Discover layer to confirm data-source availability.
- Log the run into DeepRun for replayability and add a Vercel Cron trigger to run the health-check on the autonomous heartbeat.

## Acceptance Criteria
All six Google services return status='connected' in their ConnectorStatus records with valid non-expired tokens, expired tokens are auto-refreshed and persisted, the aggregated health summary reports 6/6 healthy, and a DeepRun log entry is created for the execution.
