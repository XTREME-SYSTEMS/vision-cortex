## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes OAuth for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function that reads stored Google OAuth credentials from the Supabase secrets/credentials store for each connected service
- Validate each service token by issuing a lightweight authenticated call (Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets spreadsheets metadata, Tasks tasklists, Search Console sites.list)
- Detect expired tokens and refresh them using the stored refresh_token via the Google OAuth token endpoint, persisting updated access_tokens back to Supabase
- Record per-service connection status, granted scopes, last-checked timestamp, and error details into a GoogleConnector entity in Base44
- Expose an aggregated health payload to the Discover layer so downstream intelligence loops know which Google data sources are live
- Log the run to DeepRun for replayability and emit failures to the alerting channel

## Acceptance Criteria
Invoking syncGoogleWorkspaceConnectors returns status:'ok' with all six services (drive, calendar, gmail, sheets, tasks, search_console) reporting connected:true, valid non-expired tokens persisted in Supabase, a GoogleConnector entity updated with last-checked timestamps and scopes, and a DeepRun log entry created; any service failing produces a clear error and does not block the others.
