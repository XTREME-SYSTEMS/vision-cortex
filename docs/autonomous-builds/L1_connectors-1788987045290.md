## Summary
Build a unified Google Workspace connector service that verifies and manages OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorManager` that centralizes OAuth token storage and refresh for all six Google services
- Define a `GoogleConnection` entity storing service name, scopes, access/refresh tokens, expiry, and health status
- Implement per-service scope validation ensuring required OAuth scopes are granted (drive.readonly, calendar, gmail.readonly, spreadsheets, tasks, webmasters.readonly)
- Add a token refresh routine that auto-renews expired access tokens using stored refresh tokens
- Implement a health-check probe that makes a minimal read call to each service API and records success/failure
- Expose a status summary endpoint returning connection health for all six connectors
- Wire connector health into the Discover layer so downstream intelligence functions can query available data sources
- Log all connection events to DeepRun for replayability

## Acceptance Criteria
Calling googleConnectorManager with action=status returns all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with connected=true and a passing health-check probe; expired tokens auto-refresh; each service's required scopes are validated and connection events are logged to DeepRun.
