## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that verifies and refreshes OAuth access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that iterates over the six authorized Google services.
- Load stored OAuth credentials/refresh tokens per service from Supabase secure config table `google_connectors`.
- For each service, call a lightweight health-check endpoint (Drive: files.list?pageSize=1, Calendar: calendarList.list, Gmail: users.getProfile, Sheets: no-op token validation, Tasks: tasklists.list, Search Console: sites.list).
- Refresh any expired access tokens via the Google OAuth token endpoint using the refresh_token and update Supabase.
- Record per-service status (connected, degraded, failed), scopes, and last_checked timestamp into the `google_connectors` entity.
- Emit a consolidated connector health record to CoreDocument/DeepRun log for the Discover layer.
- Expose the aggregate status via return payload for the autonomous heartbeat (Vercel Cron) to consume.
- Schedule `googleConnectorSync` on the existing Vercel Cron heartbeat every 30 minutes.

## Acceptance Criteria
Invoking googleConnectorSync returns a status object listing all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) each with status 'connected', valid non-expired access tokens persisted in Supabase, and a health record written to DeepRun; expired tokens are auto-refreshed and any failure is flagged with a diagnostic reason.
