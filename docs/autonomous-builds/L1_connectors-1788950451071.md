## Summary
Build a unified Google Workspace connector verification and health-check function that confirms all authorized core connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) are connected and operational.

## Steps
- Create a Base44 backend function `verifyGoogleConnectors` in Deno/TypeScript that reads stored OAuth credentials for the Google Workspace integration
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) issue a lightweight authenticated probe request (e.g. Drive files.list?pageSize=1, Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets metadata ping, Tasks tasklists.list, Search Console sites.list)
- Capture per-service status, granted scopes, token expiry, and any auth errors
- Auto-refresh expired access tokens using the stored refresh token before probing
- Persist a ConnectorHealth record per service to the Base44 entity store with fields: service, connected(bool), scopes, lastChecked, latencyMs, error
- Aggregate results into a single Discover-layer readiness payload and surface it to the system dashboard
- Log the run to DeepRun for replayability and emit an alert if any connector reports connected=false

## Acceptance Criteria
Invoking verifyGoogleConnectors returns connected=true for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with valid non-expired tokens and granted scopes, a ConnectorHealth record is persisted for each, the run is logged to DeepRun, and any failure triggers an alert.
