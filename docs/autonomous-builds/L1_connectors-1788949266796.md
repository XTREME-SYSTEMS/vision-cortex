## Summary
Verify, harden, and register the authorized Google Workspace connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) as validated Discover-layer data sources with health checks and unified access.

## Steps
- Enumerate the six authorized Google connectors and confirm each OAuth token/scope is valid and refreshable via the Google Workspace integration credentials store.
- Create or update a ConnectorRegistry entity record for each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with fields: service, status, scopes, lastHealthCheck, tokenExpiry.
- Implement a per-service health probe: Drive files.list(pageSize=1), Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets.get on a canary sheet, Tasks tasklists.list, Search Console sites.list.
- Add automatic token refresh handling and mark any connector with expired/invalid tokens as status=degraded and emit an alert.
- Wire the validated connectors into the Discover layer as registered Data Sources so Understand/Predict layers can query them.
- Persist a health summary to CoreDocument and log the run to DeepRun for replayability.
- Schedule a recurring Vercel Cron heartbeat to re-run the health check every 6 hours.

## Acceptance Criteria
All six connectors return status=healthy from their respective probe calls, each has a ConnectorRegistry record with a fresh lastHealthCheck timestamp and non-expired token, they are registered as Discover-layer data sources, a health summary is written to CoreDocument, a DeepRun log entry exists, and the 6-hour cron job is active.
