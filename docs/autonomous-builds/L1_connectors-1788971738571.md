## Summary
Build a unified Google Workspace connector health-check and token-refresh service that validates and maintains the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections.

## Steps
- Create a Base44 backend function `googleConnectorManager` (Deno/TypeScript) that reads stored OAuth credentials from the Supabase `google_connections` table
- Implement per-service health-check probes: Drive (files.list), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets.get on a test sheet), Tasks (tasklists.list), Search Console (sites.list)
- Add automatic OAuth token refresh using the stored refresh_token when access_token is expired or a 401 is returned
- Persist connection status (service, status, last_checked, scopes, error) back to the Supabase `google_connections` table for zero-credit reads
- Expose a normalized status summary response and log the run to DeepRun for replayability
- Register a Vercel Cron heartbeat (hourly) to invoke the function and re-validate all six connectors
- Emit alerts to the Council/IntelFeed when any connector degrades so the Discover layer can adapt

## Acceptance Criteria
Invoking googleConnectorManager returns HTTP 200 with a status object listing all six Google services each marked 'connected', expired tokens are auto-refreshed without manual intervention, the Supabase google_connections table reflects updated last_checked timestamps and scopes, and the run is logged in DeepRun with the hourly Vercel cron confirmed firing.
