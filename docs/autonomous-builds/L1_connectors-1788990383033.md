## Summary
Build a unified Google Workspace connector health-verification and sync orchestrator that validates and manages the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Create a Base44 backend function `verifyGoogleConnectors` (Deno/TypeScript) that iterates over the six authorized Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).
- For each service, perform a lightweight authenticated read call (e.g. Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) using the stored OAuth token.
- Detect expired/invalid tokens and trigger the OAuth refresh flow, persisting refreshed tokens to the connector credential store.
- Write a ConnectorStatus record per service to the Base44 entity (service name, scopes, last_verified_at, health status, error detail) and mirror to Supabase for zero-credit reads.
- Emit an aggregated health summary event into the Discover layer so downstream state machines can rely on connector availability.
- Schedule the function on Vercel Cron (heartbeat) to re-verify connectors periodically and alert on degradation.
- Add unit/integration coverage using @/ import aliases and lucide-react icons for any status UI, keeping components under 50 lines each.

## Acceptance Criteria
Invoking verifyGoogleConnectors returns a status object listing all six Google services with health=healthy and a fresh last_verified_at timestamp; expired tokens are auto-refreshed; a ConnectorStatus record exists per service in both Base44 and Supabase; the Vercel cron entry is registered and re-runs successfully on schedule.
