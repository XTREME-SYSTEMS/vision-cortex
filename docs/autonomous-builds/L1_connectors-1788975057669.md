## Summary
Build a unified Google Workspace connector health-check and normalization layer that validates and registers Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections into the Discover layer.

## Steps
- Enumerate the six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) from the OAuth credential store
- For each connector, invoke a lightweight read-only probe call to confirm token validity and required scopes
- Normalize each connector's status into a ConnectorRegistry entity record (name, scopes, status, last_checked, token_expiry)
- Detect and flag any missing scopes or expired tokens, queuing them for re-auth
- Persist connector metadata to Supabase for zero-credit status reads by the Discover layer
- Emit a consolidated health report to CoreDocument and register connectors as active Discover data sources
- Schedule a Vercel Cron heartbeat to re-run the health check periodically and auto-refresh tokens

## Acceptance Criteria
All six connectors return a passing read-only probe, each has a ConnectorRegistry record with status='active' persisted to Supabase, expired/missing-scope connectors are flagged for re-auth, and the Discover layer can query connector availability without consuming credits.
