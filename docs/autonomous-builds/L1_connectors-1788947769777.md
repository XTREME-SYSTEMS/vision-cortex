## Summary
Build a unified Google Workspace connector health-check and orchestration function that verifies and consolidates the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors into the Discover layer.

## Steps
- Enumerate all six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and load their stored OAuth credentials from the secure credential store
- Implement a per-connector token validation and refresh routine that exchanges refresh tokens and updates expiry metadata
- Perform a lightweight read probe against each API (e.g., Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live scope access
- Register each verified connector as a Discover-layer data source in the Base44 entity registry with status, scopes, and last-verified timestamp
- Write a consolidated ConnectorHealth record to Supabase for zero-credit status querying by autonomous loops
- Emit structured errors for any connector failing validation and mark it degraded rather than blocking others
- Expose the aggregate result so the Vercel cron heartbeat can monitor connector health each epoch

## Acceptance Criteria
Function returns a status object listing all six connectors each marked 'connected' with valid refreshed tokens and a successful read probe; ConnectorHealth records persisted to Supabase and Base44 registry; any failing connector is reported as 'degraded' with an error reason without aborting the others; cron can invoke it idempotently each epoch.
