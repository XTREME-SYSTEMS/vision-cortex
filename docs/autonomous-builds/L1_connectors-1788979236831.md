## Summary
Build a unified Google Workspace connector service that validates and health-checks the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Create a Base44 backend function 'googleConnectorHealth' in Deno/TypeScript that accepts a list of Google service scopes to verify
- Load stored OAuth credentials/refresh tokens from Supabase for the connected Google Workspace account
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), issue a lightweight authenticated ping call (e.g. Drive about.get, Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets metadata, Tasks tasklists.list, Search Console sites.list)
- Refresh expired access tokens automatically using the stored refresh token and persist the new token back to Supabase
- Record per-service status (connected/degraded/failed), latency, and granted scopes into a Base44 'IntegrationStatus' entity
- Return a consolidated health report and surface any missing scopes or auth errors for remediation
- Register the function on the Vercel Cron heartbeat to re-validate connectors every 6 hours

## Acceptance Criteria
Invoking googleConnectorHealth returns a report showing all six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with status 'connected', valid non-expired tokens persisted in Supabase, an IntegrationStatus entity record written per service, and the cron job scheduled to re-run every 6 hours.
