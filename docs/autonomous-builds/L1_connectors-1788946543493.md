## Summary
Build a unified Google Workspace connector service that authorizes and health-checks all six core Google integrations (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) under the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorManager` (Deno/TypeScript) that centralizes OAuth token storage and refresh for all Google Workspace scopes.
- Define the OAuth scope set: drive.readonly/file, calendar, gmail.readonly/send, spreadsheets, tasks, webmasters.readonly for Search Console.
- Store connector credentials and refresh tokens in a Supabase `google_connectors` table (zero-credit external store), keyed by connector name and account.
- Implement per-service health-check calls (Drive files.list, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) returning connected/error status.
- Add automatic token refresh logic triggered when a health-check returns 401, persisting the new access token.
- Register the connector status into the Discover-layer data sources so downstream Understand/Predict layers can query availability.
- Expose a `status` action returning a consolidated JSON map of all six connectors with last-checked timestamps.
- Wire a Vercel Cron heartbeat to invoke the health-check action periodically and flag any degraded connector.

## Acceptance Criteria
Invoking googleConnectorManager with action=status returns all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) marked connected:true with valid non-expired tokens, health-check API calls succeed with 200 responses, credentials persist in the Supabase google_connectors table, and expired tokens auto-refresh without manual re-authorization.
