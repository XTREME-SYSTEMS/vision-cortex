## Summary
Build a unified Google Workspace connector health-check and orchestration function that validates and registers the six authorized Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) into the Discover layer.

## Steps
- Define a ConnectorRegistry Base44 entity capturing service name, OAuth scope, status, last_verified, and token_expiry for each Google service
- Implement OAuth token retrieval and refresh logic using stored Google Workspace credentials for each of the six services
- For each service, perform a lightweight validation call (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata ping; Tasks: tasklists.list; Search Console: sites.list)
- Record each validation result (connected/degraded/failed) with timestamp into ConnectorRegistry
- Wire successful connectors into the Discover layer data-source manifest so intelligence gathering can consume them
- Expose a summary payload of connector statuses and emit a DeepRun log entry for replayability
- Schedule the health-check via Vercel Cron heartbeat to re-verify tokens before expiry

## Acceptance Criteria
ConnectorRegistry contains six entries (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) each with status 'connected', a recent last_verified timestamp, and a valid non-expired token; a DeepRun log records the verification run and the Discover layer manifest lists all six services as active data sources.
