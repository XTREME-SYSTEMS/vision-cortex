## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections feeding the Discover layer.

## Steps
- Enumerate the six authorized Google service connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) from the integration registry
- For each connector, validate stored OAuth tokens and auto-refresh any expired access tokens using stored refresh tokens
- Perform a lightweight read probe per service (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: labels.list; Sheets: spreadsheets metadata ping; Tasks: tasklists.list; Search Console: sites.list) to confirm live scope access
- Record per-connector status (connected/degraded/failed), granted scopes, and last-verified timestamp into a Supabase 'connector_health' table for zero-credit tracking
- Emit a normalized ConnectorStatus summary into the Discover-layer data plane so downstream Understand/Predict layers can query source availability
- Log the full run to DeepRun for replayability and surface any failed connector requiring re-authorization
- Return an aggregate report with overall health flag and remediation actions for any degraded connectors

## Acceptance Criteria
Function returns a report where all six connectors show status 'connected' with valid non-expired tokens, verified scopes, and fresh last-verified timestamps persisted in Supabase connector_health; a DeepRun log entry exists for the run; any failed connector is flagged with a re-authorization action and the aggregate overall_health flag reflects true only when all six pass their read probes.
