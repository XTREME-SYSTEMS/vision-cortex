## Summary
Build a unified Google Workspace connector health-check and integration layer that validates and registers OAuth access across Drive, Calendar, Gmail, Sheets, Tasks, and Search Console for the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorSync` that reads stored OAuth credentials for the Vision Cortex Google Workspace integration
- Verify OAuth token validity and refresh expired tokens using the stored refresh_token before each scope test
- Iterate through the six required scopes (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and issue a lightweight read probe against each API (e.g. drive.about.get, calendar.calendarList.list, gmail.users.getProfile, sheets ping, tasks.tasklists.list, searchconsole.sites.list)
- Record per-connector status (connected/degraded/failed), last_checked timestamp, and granted scopes into a Base44 `ConnectorStatus` entity
- Log the full sync run to DeepRun for replayability and expose an aggregate health object for the Discover layer to consume
- Emit a Discover-layer event when all six connectors report connected, closing the architecture gap
- Handle and surface actionable errors (missing scope, revoked token, quota exceeded) without leaking secrets

## Acceptance Criteria
Invoking googleConnectorSync returns a JSON report listing all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) each with status='connected', valid granted scopes, and a fresh last_checked timestamp; a corresponding ConnectorStatus entity row is persisted per connector, a DeepRun log entry exists for the sync, and the Discover layer can read the aggregate health object showing all connectors healthy.
