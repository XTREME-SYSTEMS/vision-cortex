## Summary
Build a unified Google Workspace connector health-check and token-refresh function that verifies Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections are authorized and operational.

## Steps
- Create a Base44 backend function `verifyGoogleConnectors` in Deno/TypeScript that reads stored OAuth credentials for each Google service
- Iterate over the six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and perform a lightweight authenticated read call per service to confirm the token is valid
- For any service returning a 401/403, attempt a silent token refresh using the stored refresh_token against Google OAuth token endpoint
- Persist connector status (service, authorized boolean, scopes, last_checked, expiry) to a Base44 entity `GoogleConnectorStatus` for observability
- Log the health-check run to DeepRun with per-service outcomes for replayability
- Expose an aggregate readiness flag so the Discover layer can gate data-source usage on connector availability
- Schedule the function via Vercel Cron heartbeat to run periodically and proactively refresh expiring tokens

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return authorized=true in the GoogleConnectorStatus entity, expired tokens are auto-refreshed, a DeepRun log entry records the run, and the aggregate readiness flag reads true; a failing service is correctly flagged authorized=false with an error reason.
