## Summary
Build a unified Google Workspace connector health-verification and sync orchestration layer that validates and coordinates the already-authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors.

## Steps
- Create a Base44 backend function that enumerates all authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and reads their stored OAuth credentials from Supabase.
- For each connector, perform a lightweight authenticated ping (e.g. Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to verify token validity and scope coverage.
- Detect expired or near-expired tokens and trigger the OAuth refresh flow, persisting refreshed tokens back to Supabase for zero-credit reuse.
- Write a normalized connector health record per service (status, scopes, last_checked, latency, error) into a Base44 GoogleConnectorHealth entity.
- Register the sync orchestration as a Vercel Cron heartbeat so connector health is re-validated on the autonomous loop.
- Emit a consolidated status summary to CoreDocument/architecture Data Plane and surface failures to the Council for the Understand layer.
- Return an aggregate result object indicating overall Discover-layer Google data source readiness.

## Acceptance Criteria
All six Google connectors return status='healthy' with valid non-expired tokens and required scopes; a GoogleConnectorHealth record exists per service updated within the last cron cycle; the aggregate response reports overall_ready=true; and any refresh events are persisted to Supabase without consuming credits.
