## Summary
Build a unified Google Workspace connector health-check and token-refresh function that validates and maintains all authorized core infrastructure connections (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `verifyGoogleConnectors` in Deno/TypeScript that reads stored OAuth credentials for the Google Workspace integration.
- For each connector (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), issue a minimal read-only probe API call to confirm the token scope is valid and the service responds.
- Detect expired or near-expiry access tokens and refresh them using the stored refresh_token via the Google OAuth2 token endpoint.
- Persist refreshed tokens and per-connector health status (connector name, status, scopes, last_checked, expires_at) into a Supabase table `google_connector_status` for zero-credit reads.
- Emit a consolidated health report entity and log the run to DeepRun for replayability.
- Register a Vercel Cron heartbeat to invoke this function on a schedule so connectors remain continuously authorized.
- Surface connector status in the Discover layer so downstream intelligence gathering can rely on live Google services.

## Acceptance Criteria
All six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' with valid non-expired tokens; the google_connector_status table reflects a recent last_checked timestamp for each; expired tokens are automatically refreshed; and a DeepRun log records the successful health check with the cron heartbeat scheduled.
