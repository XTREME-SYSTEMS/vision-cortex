## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes OAuth for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function that enumerates all authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console)
- For each connector, verify stored OAuth tokens exist and refresh expired access tokens using the refresh_token grant
- Perform a lightweight read probe per service (e.g., Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list)
- Persist connector status (connected/degraded/failed), last_checked timestamp, and scope coverage into the ConnectorStatus Base44 entity
- Emit an IntelFeed/system event summarizing connector health for the Discover layer
- Schedule the function on Vercel Cron heartbeat to run periodically for autonomous re-validation
- Return a structured report with per-service status and any remediation actions needed

## Acceptance Criteria
Function returns a report listing all six Google services with status 'connected', valid non-expired access tokens, successful read probes, and a ConnectorStatus entity record updated with last_checked timestamp for each service; degraded/failed services include a remediation reason.
