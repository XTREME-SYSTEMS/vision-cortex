## Summary
Build a unified Google Workspace connector health-check and orchestration function that validates and registers the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors into the Discover layer.

## Steps
- Create a Base44 backend function `syncGoogleConnectors` in Deno/TypeScript that reads stored OAuth tokens for the Google Workspace service account
- For each connector (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) perform a lightweight authorized API probe to confirm scope validity and token freshness
- Refresh any expired OAuth tokens using the stored refresh_token and persist updated credentials to Supabase (zero-credit external store)
- Register each verified connector as a Discover-layer data source in the Base44 entity registry with status, scopes, and last_verified timestamp
- Emit a structured health report entity capturing per-connector status (ok/degraded/failed) and error details
- Wire the function into Vercel Cron heartbeat for periodic re-validation of connector health
- Log execution to DeepRun for replayable, validated auditing

## Acceptance Criteria
Function returns a report where all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report status 'ok' with valid non-expired tokens; a ConnectorHealth entity is persisted with last_verified timestamps; the connectors appear as registered Discover-layer data sources; and a DeepRun log entry exists for the execution.
