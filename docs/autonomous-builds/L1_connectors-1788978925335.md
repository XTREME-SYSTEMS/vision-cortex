## Summary
Build a unified Google Workspace connector service that validates and health-checks the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Create a Base44 backend function `googleConnectorHealth` in Deno/TypeScript that iterates over each authorized Google service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).
- For each service, perform a lightweight read-only probe (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata ping; Tasks: tasklists.list; Search Console: sites.list) using stored OAuth tokens.
- Implement automatic OAuth token refresh when a 401 is returned, persisting refreshed tokens to the Base44 credentials entity.
- Record each probe result (service, status, latency_ms, scopes, last_checked) into a new Base44 `ConnectorStatus` entity keyed by service name.
- Expose a normalized response summarizing per-service health and overall connector readiness for the Discover layer.
- Register a Vercel Cron heartbeat to invoke `googleConnectorHealth` every 15 minutes for continuous monitoring.
- Emit alerts to the system log when any connector transitions to a degraded or failed state.

## Acceptance Criteria
Invoking googleConnectorHealth returns status 'ok' for all six Google services with valid refreshed tokens, writes a ConnectorStatus record per service, the Vercel cron fires every 15 minutes, and any 401 triggers a successful token refresh without manual intervention.
