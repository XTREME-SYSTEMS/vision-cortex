## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes all authorized core infrastructure connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `syncCoreConnectors` in Deno/TypeScript that iterates over the six authorized Google services.
- For each service, validate the stored OAuth token, refreshing via the Google token endpoint if expired, and persist updated credentials to the ConnectorCredential entity.
- Perform a lightweight read probe per service (Drive: files.list limit 1, Calendar: calendarList.list, Gmail: labels.list, Sheets: spreadsheets metadata ping, Tasks: tasklists.list, Search Console: sites.list) to confirm live connectivity.
- Record each probe result (status, latency, scopes granted, last_synced_at) into a ConnectorHealth entity in Supabase for zero-credit observability.
- Emit an aggregated health report and flag any connector with degraded/expired status for the Discover layer.
- Register the function with Vercel Cron to run on the autonomous heartbeat every 6 hours.
- Expose results to the Discover layer so Google services can feed the 4-layer intelligence pipeline.

## Acceptance Criteria
Invoking syncCoreConnectors returns a report where all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report status=healthy with valid non-expired tokens, each probe succeeds with recorded latency, ConnectorHealth rows are written to Supabase, and the cron job is registered and executes on schedule.
