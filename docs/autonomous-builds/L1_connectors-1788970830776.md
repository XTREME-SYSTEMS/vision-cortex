## Summary
Build a unified Google Workspace connector layer that verifies and persists OAuth-authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console for the Discover layer.

## Steps
- Define a GoogleConnector Base44 entity capturing service name, scopes, OAuth token reference, connection status, and last verified timestamp for each of the six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console)
- Implement the connectGoogleServices backend function to validate stored OAuth credentials against each Google API with a lightweight read call (Drive files.list, Calendar calendarList, Gmail profile.get, Sheets spreadsheets.get on a probe sheet, Tasks tasklists.list, Search Console sites.list)
- Persist per-service connection status and scopes into the GoogleConnector entity, marking each as connected/failed with error detail
- Store refresh tokens securely in Supabase for zero-credit reuse and wire token refresh handling
- Expose a health-check summary consumable by the Discover layer, and log the verification run to DeepRun for replayability
- Emit an aggregate connectorsReady flag when all six services report connected

## Acceptance Criteria
connectGoogleServices returns connectorsReady=true with all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) showing status 'connected', GoogleConnector entities are persisted with valid scopes and recent lastVerified timestamps, refresh tokens are stored in Supabase, and a corresponding DeepRun log entry records the successful verification.
