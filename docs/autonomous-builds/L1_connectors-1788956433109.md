## Summary
Build a unified Google Workspace connector service that verifies and health-checks the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations, persisting connection status to Base44 entities.

## Steps
- Create a ConnectorRegistry Base44 entity to track each Google service (service_name, scopes, status, last_verified, token_expiry, error).
- Implement OAuth token refresh handling using stored Google Workspace credentials, ensuring refresh tokens are persisted securely in Supabase.
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight read probe (e.g., Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list).
- Record probe results (ok/expired/error) with timestamps into ConnectorRegistry.
- Expose a health summary endpoint returning per-service status for the Discover layer to consume.
- Register a Vercel Cron heartbeat to re-verify connectors every 6 hours and auto-refresh expiring tokens.
- Emit a DeepRun log entry documenting the connector verification epoch.

## Acceptance Criteria
Calling verifyGoogleConnectors returns status 'ok' for all six Google services, ConnectorRegistry entities show last_verified within the last hour with valid non-expired tokens, the health summary endpoint lists all six as connected, and the cron heartbeat is registered and logs a successful DeepRun entry.
