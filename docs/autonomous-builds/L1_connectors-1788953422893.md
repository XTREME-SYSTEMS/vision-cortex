## Summary
Build a unified Google Workspace connector service that validates and health-checks the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Create a Base44 backend function `googleConnectorManager` that centralizes OAuth token retrieval and refresh for all Google Workspace scopes
- Define a connector registry mapping each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) to its API base URL, required scopes, and a lightweight health-check endpoint
- Implement token refresh logic using the stored Google refresh token, persisting refreshed access tokens to the Supabase external store (zero-credit)
- For each connector, perform a minimal read call (e.g. Drive about.get, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites list) to confirm live connectivity
- Record connector status (connected/degraded/failed), last-checked timestamp, granted scopes, and latency into a `ConnectorStatus` Base44 entity
- Expose the aggregated status as the function response and log the run to DeepRun for replayability
- Wire a Vercel cron heartbeat to invoke the health check on a recurring interval for autonomous self-healing

## Acceptance Criteria
Invoking googleConnectorManager returns a status object listing all six Google services with state 'connected', valid non-expired access tokens, verified scopes, and a successful minimal API read for each; ConnectorStatus entities are persisted and the run appears in DeepRun logs.
