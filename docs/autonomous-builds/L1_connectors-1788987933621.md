## Summary
Build a unified core infrastructure connector service that validates, persists, and health-checks the authorized Google Workspace connections (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `syncCoreConnectors` in Deno/TypeScript that accepts the list of authorized Google service connectors
- Define a `CoreConnector` Base44 entity with fields: service, status, scopes, tokenRef, lastHealthCheck, expiresAt
- For each connector, verify the stored OAuth token by making a minimal read-only API call (Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list)
- Persist each connector's health result and granted scopes to the CoreConnector entity in Supabase for zero-credit reads
- Register a Vercel Cron heartbeat to re-run `syncCoreConnectors` hourly to detect token expiry and trigger refresh
- Emit a consolidated status document to CoreDocument and surface connector health in the Discover layer data sources registry
- Add automatic token refresh logic using stored refresh tokens when expiresAt is within 5 minutes

## Acceptance Criteria
All six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' with valid scopes, each has a lastHealthCheck timestamp within the last hour, CoreConnector entities are persisted in Supabase, and the hourly cron successfully refreshes any token nearing expiry without manual intervention.
