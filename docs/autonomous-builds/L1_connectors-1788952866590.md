## Summary
Build a unified Google Workspace connector health-check and integration registry that verifies and persists the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections.

## Steps
- Create a Base44 backend function 'connectorRegistry' that enumerates all authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).
- For each connector, perform a lightweight authenticated probe (e.g., Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) using stored OAuth tokens.
- Refresh any expired OAuth tokens via the Google token endpoint and persist new access/refresh tokens to the Supabase 'connector_credentials' store.
- Write/update a 'ConnectorStatus' Base44 entity row per connector with fields: name, scope, status (connected|degraded|failed), last_checked, latency_ms, error.
- Expose an aggregated health summary consumable by the Discover layer so downstream state machines can gate on connector availability.
- Register the connector health-check on the Vercel cron heartbeat to re-validate on a recurring schedule.
- Emit a DeepRun log entry recording the verification outcome for replayability.

## Acceptance Criteria
Invoking connectorRegistry returns status 'connected' for all six Google connectors with a valid last_checked timestamp and non-null latency; ConnectorStatus entities are persisted in Base44, refreshed tokens are stored in Supabase, a DeepRun log entry exists, and the cron heartbeat re-runs the check on schedule.
