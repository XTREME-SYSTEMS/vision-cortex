## Summary
Build a unified Google Workspace connector health-check and orchestration function that verifies and registers the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors into the Discover layer's data plane.

## Steps
- Create a Base44 backend function `googleConnectorOrchestrator` in Deno/TypeScript that accepts a list of connector scopes to validate.
- For each connector (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authenticated ping to its respective Google API endpoint using stored OAuth credentials.
- Record connector status (connected/degraded/failed), token expiry, and granted scopes into a Base44 `ConnectorRegistry` entity.
- Register each healthy connector as a Discover-layer data source so it feeds the 4-Layer intelligence architecture.
- Refresh any expiring OAuth tokens and log refresh events to DeepRun execution logs.
- Emit a consolidated health report and expose it via the function response for the autonomous heartbeat (Vercel Cron) to consume.
- Add a scheduled cron entry to re-run the orchestrator hourly to maintain connector liveness.

## Acceptance Criteria
Invoking googleConnectorOrchestrator returns a report showing all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with status 'connected', valid non-expired tokens, and each registered as an active Discover-layer data source in the ConnectorRegistry entity; the hourly cron re-runs successfully and logs to DeepRun.
