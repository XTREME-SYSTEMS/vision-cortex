## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes all authorized core infrastructure connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `syncCoreConnectors` in Deno/TypeScript that iterates over the six authorized Google connectors.
- For each connector, verify the stored OAuth token validity and refresh expired tokens using the Google OAuth refresh endpoint.
- Perform a lightweight authorized read per service (Drive: files.list limit 1; Calendar: calendarList; Gmail: profile; Sheets: spreadsheets metadata ping; Tasks: tasklists; Search Console: sites.list) to confirm live access.
- Record each connector's status, last-checked timestamp, token expiry, and any error into a `ConnectorStatus` Base44 entity (create the entity if absent).
- Emit a consolidated health summary to CoreDocument/architecture Data Plane log and flag any degraded connector for re-authorization.
- Wire the function into a Vercel Cron heartbeat (every 6 hours) for autonomous re-validation.
- Use @/ alias imports, lucide-react icons for any status UI, and keep components under 50 lines each.

## Acceptance Criteria
Invoking syncCoreConnectors returns HTTP 200 with a JSON report listing all six connectors as status:'connected' with valid non-expired tokens and successful live read checks; ConnectorStatus entities are persisted with fresh timestamps; and the Vercel cron entry is registered and fires on schedule.
