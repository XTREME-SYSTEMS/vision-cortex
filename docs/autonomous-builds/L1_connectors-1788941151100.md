## Summary
Build a unified Google Workspace connector health-check and status registry that verifies and persists connectivity for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `verifyGoogleConnectors` that iterates over the six authorized Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).
- For each service, perform a lightweight read call using the stored OAuth token: Drive files.list(pageSize=1), Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets metadata ping, Tasks tasklists.list, Search Console sites.list.
- Capture per-service status (connected/error), token expiry, granted scopes, and last-checked timestamp.
- Upsert results into a `ConnectorStatus` Base44 entity keyed by service name.
- Trigger automatic token refresh via stored refresh_token when a 401/expired response is detected, then re-test.
- Expose a summary object and register a Vercel cron heartbeat to re-run the check every 6 hours for autonomous monitoring.
- Surface aggregate health on the Discover-layer dashboard so downstream DEEP state machines can gate on connector readiness.

## Acceptance Criteria
Invoking verifyGoogleConnectors returns status 'connected' for all six services with valid non-expired tokens, ConnectorStatus entities are upserted with fresh last-checked timestamps, expired tokens auto-refresh successfully, and the cron job runs on schedule without errors.
