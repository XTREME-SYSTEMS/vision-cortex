## Summary
Build a unified Google Workspace connector service that validates and manages authorized OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console within the Discover layer.

## Steps
- Create a Base44 backend function `googleWorkspaceConnector.js` in Deno/TypeScript that centralizes OAuth token retrieval, refresh, and per-service client instantiation
- Store and manage OAuth credentials and refresh tokens in Supabase (zero-credit external store) under a `google_connections` table keyed by service and account
- Implement per-service health-check probes: Drive (files.list), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets metadata read), Tasks (tasklists.list), Search Console (sites.list)
- Add automatic token refresh logic that detects expired access tokens and refreshes using stored refresh tokens, updating Supabase
- Expose a `status` action returning the connection state of each of the six services for the Discover layer to consume
- Register the connector as a Discover-layer data source and log validation results to DeepRun execution logs
- Wire error handling and structured logging so failed connections surface as gaps back into the system

## Acceptance Criteria
Invoking the function with the status action returns a healthy connection result for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), each returning live API data from its probe, expired tokens auto-refresh successfully, and connection states are persisted in Supabase and logged to DeepRun.
