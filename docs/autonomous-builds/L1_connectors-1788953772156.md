## Summary
Build a unified Google Workspace connector health-check and integration layer that validates and registers the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors into the Discover layer.

## Steps
- Enumerate the six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and confirm OAuth scopes/tokens are stored in Supabase secrets
- Create a Base44 backend function that performs a lightweight authenticated ping against each Google API endpoint to validate live connectivity
- Register each validated connector as a Discover-layer data source in the Base44 entity registry with status, last_checked, and scope metadata
- Implement token-refresh handling and error capture for any connector returning 401/403
- Emit a DeepRun execution log recording the health-check results for replayability
- Surface connector status on the system dashboard via a small React status component using lucide-react icons

## Acceptance Criteria
