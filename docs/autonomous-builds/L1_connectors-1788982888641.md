## Summary
Build a unified Google Workspace connector service that verifies and manages OAuth connectivity across Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleWorkspaceConnector` that centralizes OAuth token storage and refresh for all six Google services
- Add a GoogleConnection entity (Supabase) storing service name, scope, access_token, refresh_token, expiry, and status per authorized service
- Implement a token refresh routine that checks expiry and refreshes via Google OAuth2 endpoint before each service call
- Expose per-service health-check methods (drive.about.get, calendar.list, gmail.getProfile, sheets.spreadsheets.get ping, tasks.tasklists.list, searchconsole.sites.list)
- Wire Vercel Cron heartbeat to periodically re-validate all connections and mark degraded ones
- Log connection status and errors to DeepRun execution logs for observability
- Return a consolidated connectivity report exposed to the Discover layer data sources

## Acceptance Criteria
Calling googleWorkspaceConnector with action 'verify' returns status 'connected' for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), tokens auto-refresh before expiry, GoogleConnection entities persist valid credentials, and the cron heartbeat logs a passing health report to DeepRun.
