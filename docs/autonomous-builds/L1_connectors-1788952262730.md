## Summary
Build a unified Google Workspace connector health-check and normalization layer that verifies and standardizes access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a backend function that reads stored OAuth credentials/tokens for each Google service scope (Drive, Calendar, Gmail, Sheets, Tasks, Search Console)
- Refresh expired access tokens using the stored refresh token and update the credential store
- Perform a lightweight read probe against each API (Drive: files.list limit 1, Calendar: calendarList.list, Gmail: users.getProfile, Sheets: spreadsheets metadata, Tasks: tasklists.list, Search Console: sites.list)
- Normalize each probe result into a standard connector status object {service, connected, scopes, lastChecked, error}
- Persist connector statuses to a Base44 entity (ConnectorStatus) and mirror to Supabase for zero-credit reads
- Emit a consolidated readiness signal to the Discover layer so downstream state machines can consume Google data sources
- Log the run to DeepRun for replayability and surface failures with actionable remediation messages

## Acceptance Criteria
Invoking syncGoogleWorkspaceConnectors returns a status array with all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) marked connected:true, tokens auto-refreshed when expired, ConnectorStatus entities persisted, and a DeepRun log entry created; any failing service reports a clear error and remediation hint.
