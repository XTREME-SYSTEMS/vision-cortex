## Summary
Build a unified Google Workspace connector health-check and orchestration function that verifies and registers the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations into the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorOrchestrator` in Deno/TypeScript that centralizes OAuth token retrieval for all six Google services
- Validate stored OAuth credentials/scopes for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console, refreshing expired tokens
- Perform a lightweight read probe against each service API (e.g. Drive files.list, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live connectivity
- Persist per-connector status (connected/degraded/failed, last_checked, scopes) to a Supabase `connector_status` table for zero-credit reads
- Register each healthy connector as a Discover-layer data source so intelligence loops can consume them
- Emit a consolidated health report and surface failures to the Council/Understand layer for remediation
- Add a Vercel Cron heartbeat entry to re-run the orchestrator on a schedule

## Acceptance Criteria
All six Google connectors return a 'connected' status with valid non-expired tokens, each live probe succeeds, connector_status rows are written to Supabase, the connectors are registered as Discover-layer sources, and the cron heartbeat re-runs the check without errors.
