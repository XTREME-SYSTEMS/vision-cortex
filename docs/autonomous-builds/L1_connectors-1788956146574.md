## Summary
Build a unified Google Workspace connector service that validates and health-checks the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Create a Base44 backend function `googleConnectorHealth` that reads stored OAuth tokens for the connected Google account
- Implement per-service probe calls: Drive (files.list limit 1), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets.get on a test sheet), Tasks (tasklists.list), Search Console (sites.list)
- Add token refresh logic using the stored refresh_token; persist refreshed access tokens back to the connector entity
- Record a GoogleConnector entity row per service with fields: service, status (connected/error), scopes, last_checked, error_detail
- Wire a Vercel Cron heartbeat to invoke `googleConnectorHealth` every 30 minutes for continuous validation
- Expose results to the Discover layer so downstream state machines can query connector availability
- Log all probe results to DeepRun for replayability

## Acceptance Criteria
Invoking googleConnectorHealth returns status:connected for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), a GoogleConnector entity row exists per service with a recent last_checked timestamp, token refresh succeeds without manual re-auth, and the cron heartbeat records successful runs in DeepRun.
