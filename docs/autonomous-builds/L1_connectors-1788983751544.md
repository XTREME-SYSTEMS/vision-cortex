## Summary
Build a unified Google Workspace connector health-check and orchestration function that validates and registers the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors into the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorsSync` in Deno/TypeScript that reads stored OAuth tokens for the Google Workspace integration
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) perform a lightweight authenticated ping (e.g., Drive about.get, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists.list, Search Console sites.list)
- Refresh expired OAuth tokens via the Google token endpoint and persist updated tokens to the ConnectorCredential entity
- Record each connector's status (connected/degraded/failed), scopes, and last-checked timestamp into a `ConnectorRegistry` Base44 entity
- Emit a DiscoverLayer capability event so downstream Understand/Predict/Act layers can query available data sources
- Return a consolidated health report and log the run to DeepRun for replayability

## Acceptance Criteria
All six Google connectors report status 'connected' with valid non-expired tokens in ConnectorRegistry, a DiscoverLayer capability event is emitted, and the run is logged to DeepRun with a passing health report.
