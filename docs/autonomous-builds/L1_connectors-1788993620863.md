## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and exercises all authorized Google integrations (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that reads stored OAuth credentials for each Google service from Supabase.
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), issue a lightweight authenticated probe call (e.g. Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list).
- Refresh expired access tokens using stored refresh tokens and persist updated tokens back to Supabase.
- Record per-connector status (connected/degraded/failed), latency, scopes, and last_checked timestamp into a `ConnectorStatus` Base44 entity.
- Emit an aggregated health report to the Discover layer intel feed and surface failures to the Council/Understand layer.
- Register the function on Vercel Cron heartbeat to re-validate connectors on a recurring schedule.
- Add default-exported React status panel component (<=50 lines, lucide-react icons) showing each connector's live health.

## Acceptance Criteria
Invoking googleConnectorSync returns a JSON report with an entry for each of the six Google services showing status 'connected', valid non-expired tokens persisted in Supabase, ConnectorStatus entities updated with fresh timestamps, and the status panel rendering all six connectors green; any auth failure is logged and flagged rather than silently passing.
