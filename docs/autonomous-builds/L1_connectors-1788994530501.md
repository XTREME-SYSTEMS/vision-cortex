## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and integrates the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections into the Discover layer.

## Steps
- Enumerate the six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and verify OAuth token validity and scope coverage for each.
- Implement a per-connector health probe that makes a minimal read call (e.g. Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) and records latency and status.
- Persist connector status to a Base44 entity 'ConnectorStatus' with fields: service, connected, scopes, last_checked, latency_ms, error.
- Register each healthy connector as a Discover-layer data source so it feeds the Intelligence Gathering Protocol.
- Wire a Vercel Cron heartbeat to re-run the health check on a schedule and auto-flag degraded connectors.
- Emit a consolidated summary document to CoreDocument and surface failures to the Council for deliberation.
- Add token-refresh handling so expired credentials trigger a re-auth flow rather than silent failure.

## Acceptance Criteria
All six Google connectors return a 200/OK health probe, each has a ConnectorStatus record with connected=true and populated scopes/latency, the connectors are registered as active Discover-layer data sources, and the cron heartbeat successfully re-runs the check producing an updated consolidated status document.
