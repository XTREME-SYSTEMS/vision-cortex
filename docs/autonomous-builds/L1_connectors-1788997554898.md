## Summary
Verify and harden the authorized Google Workspace core connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with a unified health-check and token-refresh layer so Layer 1 Discover can reliably ingest from all services.

## Steps
- Enumerate all six authorized Google connectors and confirm OAuth scopes and stored refresh tokens exist in Supabase secrets store
- Implement a unified connector registry entry per service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with scope, endpoint, and status fields
- Add a token-refresh routine that exchanges refresh tokens for access tokens and persists expiry, invoked on-demand and via Vercel Cron heartbeat
- Run a lightweight authenticated read against each service (Drive files.list, Calendar events.list, Gmail labels.list, Sheets spreadsheets.get, Tasks tasklists.list, Search Console sites.list) to validate live connectivity
- Record per-service health status, latency, and last-successful-sync timestamp into a ConnectorHealth Base44 entity
- Wire connector outputs into the Layer 1 Discover data plane so downstream Understand/Predict layers can consume them
- Emit a consolidated health report and surface failures for remediation

## Acceptance Criteria
All six Google connectors return status 'connected' with a fresh access token, each health check passes an authenticated read call within timeout, ConnectorHealth entity records last_successful_sync timestamps for every service, and the consolidated report shows zero failed connectors.
