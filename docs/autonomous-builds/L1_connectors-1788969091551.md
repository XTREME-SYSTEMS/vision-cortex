## Summary
Build a unified Google Workspace connector health-check and token-refresh service that validates and maintains authorized OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function 'verifyGoogleConnectors' that iterates over the six authorized Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console)
- For each service, load stored OAuth credentials from the GoogleConnector entity/Supabase secure store and check token expiry
- Refresh expired access tokens using the stored refresh_token against Google OAuth2 token endpoint, persisting new tokens
- Perform a lightweight read probe per service (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata; Tasks: tasklists.list; Search Console: sites.list) to confirm live authorization
- Record per-connector status (connected/degraded/expired), scopes, and last-verified timestamp into a ConnectorStatus entity
- Emit a consolidated health summary and surface any re-auth-required connectors to the Discover layer dashboard
- Register a Vercel Cron heartbeat to invoke this verification on a recurring interval for autonomous upkeep

## Acceptance Criteria
Invoking verifyGoogleConnectors returns a status object listing all six Google services with state 'connected', valid non-expired tokens persisted, each passing its live read probe, and a ConnectorStatus record updated with a fresh last-verified timestamp; any degraded/expired connector is flagged with a re-auth link.
