## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes OAuth tokens across Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function that enumerates all authorized Google service connections (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).
- For each service, verify the stored OAuth token in Supabase is valid; refresh via the Google token endpoint if expired.
- Perform a lightweight read probe per service (e.g. Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live connectivity.
- Persist a connector_status record per service to a Supabase table with fields: service, status, scopes, last_checked, token_expiry, error.
- Return an aggregate health report and surface failing connectors for re-authorization.
- Register a Vercel Cron heartbeat to invoke this function periodically for autonomous monitoring (Discover layer).

## Acceptance Criteria
Calling syncGoogleConnectors returns a report listing all six Google services with status 'connected', valid refreshed tokens persisted in Supabase, each service passing its read probe, and connector_status records updated with a recent last_checked timestamp; any failing service is flagged with an actionable re-auth error.
