## Summary
Build a unified Google Workspace connector service that verifies and persists OAuth-authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console for the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorSync` (Deno/TypeScript) that centralizes OAuth token retrieval and refresh for all six Google services
- Store connection metadata (service name, scopes, token expiry, account email, status) in a Supabase table `google_connections` for zero-credit persistence
- Implement per-service health checks: Drive files.list, Calendar calendarList, Gmail profile, Sheets spreadsheets.get, Tasks tasklists.list, Search Console sites.list
- Refresh expired access tokens via the stored refresh_token and update Supabase records
- Emit a consolidated connection status report to the Discover layer and log the run to DeepRun
- Expose granular error states per service so a single failing connector does not block the others
- Schedule the sync via Vercel Cron heartbeat to keep tokens live and detect revoked grants

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status='connected' with valid non-expired tokens in the `google_connections` Supabase table, each health-check API call succeeds (HTTP 200), a DeepRun log entry records the sync, and the Discover layer receives a consolidated report showing 6/6 connectors authorized.
