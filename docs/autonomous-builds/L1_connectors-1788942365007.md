## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes all authorized Google service integrations (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `googleConnectorSync` (Deno/TypeScript) that enumerates all authorized Google service connectors from the integrations config.
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), validate the stored OAuth token; refresh via Google OAuth token endpoint if expired.
- Perform a lightweight read probe per service (e.g. Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live connectivity.
- Persist a connector health record per service into a Base44 entity `ConnectorHealth` (fields: service, status, last_checked, scopes, error).
- Write refreshed tokens back to secure config storage; never log raw tokens.
- Emit a consolidated status summary to DeepRun execution logs and surface any degraded connector as an actionable alert.
- Schedule the function on Vercel Cron heartbeat (e.g. hourly) to keep connectors continuously validated.
- Add unit-testable probe wrappers per service using @/ alias imports and lucide-react icons only in any UI status component.

## Acceptance Criteria
Invoking googleConnectorSync returns a per-service status object where all six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report status 'connected' with valid non-expired tokens, a ConnectorHealth record is written for each service with a recent last_checked timestamp, and the Vercel Cron schedule triggers the function on the heartbeat without errors in DeepRun logs.
