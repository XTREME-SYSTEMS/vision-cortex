## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors as Layer 1 Discover data sources.

## Steps
- Enumerate the six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) from the integrations registry
- For each connector, validate stored OAuth tokens and refresh any that are expired or near expiry using the Google token endpoint
- Ping a lightweight read endpoint per service (e.g. Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live connectivity and required scopes
- Record connector status, scope coverage, latency, and last-sync timestamp into a Base44 ConnectorStatus entity
- Register each healthy connector as a Discover-layer data source so downstream Understand/Predict layers can query it
- Emit a consolidated health report and flag any connector needing re-authorization
- Log the run to DeepRun for replayability

## Acceptance Criteria
All six Google connectors return status=connected with valid non-expired tokens, verified live read calls succeed, required scopes are confirmed, ConnectorStatus entities are persisted with recent last-sync timestamps, and the DeepRun log shows a successful validated execution with any failing connector clearly flagged for re-auth.
