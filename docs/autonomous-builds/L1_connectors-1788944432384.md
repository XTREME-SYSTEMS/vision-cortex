## Summary
Build a unified Google Workspace connector service that validates and health-checks the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Create a Base44 backend function `googleConnectorManager` in Deno/TypeScript that centralizes OAuth token retrieval and refresh for all six Google services
- Implement per-service health check calls: Drive (files.list limit 1), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets metadata ping), Tasks (tasklists.list), Search Console (sites.list)
- Persist connector status, scopes, and last-verified timestamp to a Supabase table `google_connectors` for zero-credit reads
- Normalize error handling to detect expired/revoked tokens and trigger automatic refresh via stored refresh_token
- Expose a status summary consumable by the Discover layer so downstream intelligence flows can query connector availability
- Add structured logging to DeepRun for each verification cycle for replayability
- Wire a Vercel cron heartbeat to re-verify connectors every 6 hours

## Acceptance Criteria
Invoking googleConnectorManager returns a status object where all six services (drive, calendar, gmail, sheets, tasks, searchConsole) report `connected: true` with valid scopes and a fresh last_verified timestamp; the google_connectors Supabase table reflects the same, expired tokens auto-refresh, and a DeepRun log entry is written per cycle.
