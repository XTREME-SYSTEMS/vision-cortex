## Summary
Build a unified Google Workspace connector service that verifies and manages OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console as Layer-1 Discover data sources.

## Steps
- Create a Base44 backend function `googleConnectorManager` (Deno/TypeScript) that handles OAuth token storage, refresh, and health checks for all six Google services.
- Store connection state and encrypted refresh tokens in a Supabase table `google_connections` (columns: service, account_email, status, scopes, access_token, refresh_token, expires_at, last_verified_at).
- Implement per-service verify probes: Drive (files.list limit 1), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets.get on a probe sheet), Tasks (tasklists.list), Search Console (sites.list).
- Add automatic token refresh using the stored refresh_token when access_token is within 5 minutes of expiry.
- Register each verified service as a Layer-1 Discover data source so the Intelligence Gathering Protocol can consume it.
- Return a consolidated status report of all six connectors with connected/expired/error states.
- Log the verification run to DeepRun for replayability and score the epoch gap as closed on full success.

## Acceptance Criteria
Invoking googleConnectorManager returns status 'connected' for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with fresh last_verified_at timestamps, tokens auto-refresh without manual intervention, each connector is registered as a Layer-1 Discover source, and a DeepRun log entry records the successful verification closing the Layer 1 / Epoch 1 build gap.
