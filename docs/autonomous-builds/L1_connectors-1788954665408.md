## Summary
Build a unified Google Workspace connector service that validates and health-checks the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Create a Base44 backend function 'googleConnectorManager' that centralizes OAuth token storage and refresh for all six Google services
- Store connector credentials and scopes in a Supabase table 'google_connectors' (service, status, token_expiry, scopes, last_health_check) for zero-credit persistence
- Implement per-service health-check calls: Drive files.list, Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets.get (test sheet), Tasks tasklists.list, Search Console sites.list
- Add automatic token refresh using stored refresh tokens when token_expiry is within 5 minutes
- Register each connector as a Discover-layer data source in the intelligence architecture so downstream state machines can consume them
- Emit a consolidated status report to CoreDocument and log the run to DeepRun for replayability
- Wire a Vercel cron heartbeat to invoke the health-check every 15 minutes for self-healing

## Acceptance Criteria
Invoking googleConnectorManager returns status 'connected' for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with valid non-expired tokens, the google_connectors Supabase table reflects fresh last_health_check timestamps, and a DeepRun log entry is persisted confirming a successful replayable execution.
