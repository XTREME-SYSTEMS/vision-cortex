## Summary
Build a unified Google Workspace connector service that verifies and persists OAuth authorization for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console into the Discover layer's data plane.

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that accepts a list of Google service scopes to validate
- Load stored OAuth credentials/refresh tokens for the authorized Google account from Supabase secure store
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authorized health-check API call (e.g. Drive about.get, Calendar calendarList.list, Gmail profile.get, Sheets spreadsheets metadata ping, Tasks tasklists.list, Search Console sites.list)
- Refresh expired access tokens via the Google OAuth token endpoint and re-store them
- Upsert a `GoogleConnector` Base44 entity row per service with fields: service_name, status (connected/error), scopes, last_verified_at, account_email
- Register these connectors as active Discover-layer data sources so downstream intelligence loops can query them
- Log the sync result to DeepRun for replayability and emit a heartbeat-compatible status summary
- Return a consolidated JSON report of connection states for the six services

## Acceptance Criteria
Invoking googleConnectorSync returns status 'connected' for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), a GoogleConnector entity row exists per service with a recent last_verified_at, expired tokens are auto-refreshed, and a DeepRun log entry records the successful sync.
