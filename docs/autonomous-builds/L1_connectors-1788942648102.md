## Summary
Build a unified Google Workspace connector service that verifies and health-checks the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations within the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorManager` (Deno/TypeScript) that centralizes OAuth token retrieval and refresh for all six Google services
- Define a GoogleConnector entity (or Supabase table) storing per-service status: service name, scopes, token expiry, last health-check timestamp, connection state
- Implement per-service health-check calls: Drive files.list (pageSize=1), Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets metadata read, Tasks tasklists.list, Search Console sites.list
- Wire automatic token refresh using stored refresh tokens; log failures to DeepRun execution logs
- Expose a status endpoint returning aggregated connector health for the Discover layer dashboard
- Register a Vercel Cron heartbeat to re-run health checks periodically and persist results
- Add scope validation ensuring each service has minimum required OAuth scopes; flag insufficient grants

## Acceptance Criteria
Invoking googleConnectorManager returns a JSON report where all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report state 'connected' with valid non-expired tokens, each health-check API call returns HTTP 200, results are persisted to the GoogleConnector store, and the cron heartbeat successfully re-verifies status on schedule.
