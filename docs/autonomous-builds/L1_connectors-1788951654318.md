## Summary
Build a unified Google Workspace connector layer that validates and health-checks OAuth access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a backend function `googleConnectorSync` that reads stored OAuth credentials for the connected Google account from Supabase/Base44 entities
- Define a `GoogleConnector` entity to persist per-service connection status, scopes, token expiry, and last health-check timestamp
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) perform a lightweight authorized probe call to confirm the token and scopes are valid
- Implement automatic OAuth token refresh using the stored refresh_token when expiry is near or a 401 is returned
- Record health results (status, latency, error) for each service back into the GoogleConnector entity
- Expose a normalized status summary consumable by the Discover layer and register the function in the DeepSpec registry for replayable execution
- Wire a Vercel Cron heartbeat to invoke `googleConnectorSync` on an interval to keep connectors warm and detect revocations

## Acceptance Criteria
Invoking googleConnectorSync returns a status object with all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) reporting connected=true with valid non-expired tokens; the GoogleConnector entity is updated with fresh health-check timestamps and no scope errors; expired tokens are auto-refreshed and the cron heartbeat successfully re-runs the sync on schedule.
