## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections.

## Steps
- Create a Base44 backend function `googleConnectorSync` (Deno/TypeScript) that reads stored OAuth credentials from the connector registry entity
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), issue a lightweight authenticated ping (e.g. Drive about.get, Calendar calendarList.list, Gmail profile.get, Sheets spreadsheets metadata, Tasks tasklists.list, Search Console sites.list)
- Detect expired access tokens and refresh them using the stored refresh_token via Google OAuth2 token endpoint, persisting new tokens
- Record per-connector status (connected/degraded/failed), scopes, last_checked timestamp, and error detail into a `ConnectorStatus` Base44 entity
- Expose the aggregated health report as the function response and log to DeepRun for replayability
- Wire the function into Vercel Cron heartbeat to re-validate connectors on a schedule and alert on failures

## Acceptance Criteria
Function returns a report listing all six Google services with status 'connected', valid non-expired tokens are persisted, ConnectorStatus entities are updated with current timestamps, and the cron heartbeat successfully re-runs the check without errors.
