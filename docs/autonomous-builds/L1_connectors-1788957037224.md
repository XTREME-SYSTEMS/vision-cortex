## Summary
Build a unified Google Workspace connector health-check and token-refresh service that verifies and maintains OAuth connectivity for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function 'verifyGoogleConnectors' in Deno/TypeScript that iterates over the six authorized Google services
- For each service, load the stored OAuth credentials from Supabase (connectors table) and check token expiry
- Refresh expired access tokens using the stored refresh_token against Google's OAuth2 token endpoint and persist new tokens to Supabase
- Perform a lightweight read probe per service (Drive: files.list?pageSize=1, Calendar: calendarList.list, Gmail: users.getProfile, Sheets: spreadsheets.get on a canary sheet, Tasks: tasklists.list, Search Console: sites.list)
- Record per-service status (connected/degraded/failed), latency, and last_checked timestamp into a Supabase 'connector_health' table for zero-credit observability
- Emit a consolidated ConnectorHealth report entity in Base44 and log the run in DeepRun for replayability
- Expose scheduled invocation via Vercel Cron heartbeat to re-verify connectors periodically

## Acceptance Criteria
Function returns a report where all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report status 'connected', expired tokens are auto-refreshed and persisted to Supabase, a connector_health row exists per service with a recent last_checked timestamp, and the run is logged in DeepRun.
