## Summary
Build a unified core infrastructure connector layer that validates and health-checks the authorized Google Workspace integrations (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and registers them for use by the Discover layer.

## Steps
- Create a Base44 backend function 'connectCoreInfrastructure' that centralizes OAuth token retrieval and refresh for all six Google services
- Implement per-service health-check calls: Drive files.list, Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets.get (test sheet), Tasks tasklists.list, Search Console sites.list
- Persist connection status, scopes, and last-verified timestamp for each service into a Supabase 'connector_status' table for zero-credit reads
- Expose a normalized ConnectorRegistry entity so the Discover layer can query which data sources are live
- Add scope validation to ensure each service has the minimum required OAuth scopes and flag any missing scopes
- Implement token auto-refresh with exponential backoff and log failures to DeepRun execution logs
- Return an aggregate readiness report indicating all six connectors are authorized and healthy

## Acceptance Criteria
Invoking connectCoreInfrastructure returns status 'healthy' for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), each with valid non-expired tokens and required scopes, connector_status rows are written to Supabase, and the ConnectorRegistry entity reflects six live data sources queryable by the Discover layer.
