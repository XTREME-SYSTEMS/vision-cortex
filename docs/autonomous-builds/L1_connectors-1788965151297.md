## Summary
Build a unified Google Workspace connector health-check and orchestration function that verifies and manages OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleWorkspaceConnector` in Deno/TypeScript that centralizes OAuth token retrieval and refresh for all six Google services
- Add per-service health-check probes: Drive (files.list), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets metadata read), Tasks (tasklists.list), Search Console (sites.list)
- Persist connection status and last-verified timestamp for each service to a Supabase table `google_connector_status` for zero-credit reads
- Implement automatic token refresh using stored refresh tokens; mark service as 'degraded' and log to DeepRun on failure
- Expose a normalized response contract `{ service, connected, scopes, lastVerified, error }` per service
- Wire the connector into the Discover layer so data sources can query connection readiness before executing scraping/search tasks
- Add a Vercel Cron heartbeat entry to invoke the health-check every 15 minutes and update status

## Acceptance Criteria
Invoking googleWorkspaceConnector returns connected:true with valid scopes and a fresh lastVerified timestamp for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console); status rows are written to Supabase google_connector_status; a simulated expired token triggers automatic refresh and, on unrecoverable failure, marks the service degraded with a DeepRun log entry.
