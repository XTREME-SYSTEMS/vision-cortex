## Summary
Build a unified Google Workspace connector health-check and orchestration function that verifies and registers Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections into the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorOrchestrator` in Deno/TypeScript that accepts a list of Google service scopes to validate
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authenticated ping call to confirm OAuth token validity and scope grants
- Persist connector status records into a Base44 `ConnectorRegistry` entity with fields: service, status, scopes, lastCheckedAt, tokenExpiresAt
- Refresh any expired OAuth tokens using the stored refresh token and update the registry
- Register each healthy connector as a Discover-layer data source so intelligence loops can consume them
- Emit a consolidated health report to CoreDocument/architecture Data Plane and log a DeepRun execution record
- Wire a Vercel Cron heartbeat to invoke this function on a recurring schedule for continuous connector monitoring

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' in the ConnectorRegistry entity with valid non-expired tokens, each is registered as an active Discover-layer data source, and a DeepRun log records a successful health-check execution.
