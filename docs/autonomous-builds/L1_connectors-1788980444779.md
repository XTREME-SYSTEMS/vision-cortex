## Summary
Build a unified Google Workspace connector service that verifies and manages OAuth-authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console for the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorManager` that centralizes OAuth token retrieval, refresh, and scope validation for all six Google services
- Store connector credentials and refresh tokens in Supabase table `google_connectors` (columns: service, account_email, scopes, access_token, refresh_token, expires_at, status)
- Implement per-service health-check probes: Drive (files.list limit 1), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets.get on a test sheet), Tasks (tasklists.list), Search Console (sites.list)
- Add automatic token refresh when expires_at is within 5 minutes, updating Supabase records
- Register the connector status output as a Base44 entity `ConnectorStatus` so the Discover layer can query availability before invoking data pulls
- Add a Vercel cron heartbeat entry to re-validate all connectors every 30 minutes and flag degraded/expired connectors
- Expose a consolidated `getConnectorHealth` response listing each service's connected/expired/error state
- Log validation runs to DeepRun for replayability and audit

## Acceptance Criteria
Invoking googleConnectorManager returns status 'connected' for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with valid non-expired tokens; the ConnectorStatus entity reflects live health; expired tokens auto-refresh; and the cron heartbeat re-validates every 30 minutes with results logged to DeepRun.
