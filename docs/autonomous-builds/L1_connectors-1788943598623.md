## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that verifies and manages the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections.

## Steps
- Create a Base44 backend function `googleConnectorOrchestrator` in Deno/TypeScript that centralizes OAuth token management for all six Google services
- Store connector credentials and refresh tokens in Supabase (zero-credit external store) with a `google_connectors` table keyed by service name and account
- Implement per-service health checks: Drive (list root), Calendar (list calendars), Gmail (profile getProfile), Sheets (spreadsheets metadata ping), Tasks (tasklists list), Search Console (sites list)
- Add automatic token refresh logic using stored refresh tokens; mark connectors as degraded/expired on failure
- Persist each check result as a DeepRun execution log entry for replayability
- Expose a scheduled invocation via Vercel Cron heartbeat to re-validate connectors hourly and feed status into the Discover layer
- Return a normalized status report per service (connected | degraded | expired) with last-checked timestamp

## Acceptance Criteria
Invoking googleConnectorOrchestrator returns a status report where all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report 'connected', tokens auto-refresh without manual intervention, results are persisted to the google_connectors Supabase table and a DeepRun log, and the Vercel Cron re-validation runs on schedule.
