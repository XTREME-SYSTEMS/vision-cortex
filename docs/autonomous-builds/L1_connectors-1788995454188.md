## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that verifies and refreshes authorized connections to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that reads stored OAuth credentials for each Google service from Supabase.
- Validate each connector by issuing a lightweight authenticated ping (Drive files.list?pageSize=1, Calendar calendarList, Gmail users.getProfile, Sheets spreadsheets metadata, Tasks tasklists.list, Search Console sites.list).
- Detect expired access tokens and auto-refresh using the stored refresh_token via the Google OAuth token endpoint; persist refreshed tokens back to Supabase.
- Record per-connector status (connected, degraded, failed), last-checked timestamp, and scope coverage into a `ConnectorStatus` Base44 entity.
- Expose a normalized status summary object usable by the Discover layer so downstream intelligence gathering knows which sources are live.
- Emit failures to the system log (DeepRun) with actionable remediation (re-auth URL) and schedule periodic re-check via Vercel Cron heartbeat.
- Follow coding standards: @/ alias imports, small focused modules, lucide-react icons for any status UI.

## Acceptance Criteria
Invoking googleConnectorSync returns a status object listing all six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) each with state 'connected', a valid access token, and a recent last-checked timestamp; expired tokens are automatically refreshed and persisted, and a ConnectorStatus entity record is created/updated with zero failed connectors.
