## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Enumerate the six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and confirm OAuth scopes/tokens are stored for each in Supabase
- Implement per-connector health probes that make a minimal read call (e.g., Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list)
- Detect expired/invalid tokens and trigger refresh via stored refresh_token; persist new access tokens back to Supabase
- Normalize each connector result into a ConnectorStatus record {connector, connected, scopes, last_checked, error}
- Persist ConnectorStatus rows to a Base44 entity and emit a summary to CoreDocument system knowledge
- Register a Vercel Cron heartbeat to re-run the health check periodically for autonomous monitoring
- Surface a Discover-layer status feed so downstream Understand/Predict layers can rely on live connector availability

## Acceptance Criteria
Invoking syncGoogleConnectors returns connected:true with valid scopes and a successful test read for all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console); expired tokens are auto-refreshed; ConnectorStatus rows are persisted in Supabase/Base44; and the Vercel Cron job re-runs the check on schedule with no unhandled errors.
