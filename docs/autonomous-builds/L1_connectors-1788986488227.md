## Summary
Build a unified Google Workspace connector health-check and orchestration layer that verifies and exposes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors to the Discover layer.

## Steps
- Enumerate the six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and their stored OAuth credentials from the Base44 integrations store.
- For each connector, perform a lightweight authenticated ping (Drive: about.get; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata read; Tasks: tasklists.list; Search Console: sites.list) to confirm token validity.
- Detect and auto-refresh any expired OAuth tokens using stored refresh tokens; flag connectors requiring re-authorization.
- Persist a ConnectorStatus record per connector (name, scope, status, last_checked, latency_ms, error) into the Base44 entity store.
- Register each healthy connector as a Discover-layer data source so downstream intelligence loops can query them.
- Emit a consolidated health summary to DeepRun logs and surface any degraded connectors as actionable gaps.
- Schedule a Vercel Cron heartbeat to re-run the health check periodically for autonomous monitoring.

## Acceptance Criteria
All six Google connectors return an authenticated 200 ping, a ConnectorStatus record with status='healthy' is persisted for each, expired tokens are auto-refreshed or flagged, connectors are registered as Discover-layer data sources, and a consolidated summary is written to DeepRun logs with the cron heartbeat scheduled.
