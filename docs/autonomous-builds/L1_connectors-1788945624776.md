## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes all authorized core connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `syncGoogleConnectors` in Deno/TypeScript that iterates over the six authorized Google services.
- For each service, verify the stored OAuth token is valid; if expired, refresh it using the stored refresh token and update the credential entity in Supabase.
- Ping each API with a lightweight read call (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata; Tasks: tasklists.list; Search Console: sites.list) to confirm live connectivity.
- Record per-connector status (connected/degraded/failed), latency, scopes, and last_checked timestamp into a `ConnectorHealth` Base44 entity.
- Emit a consolidated health summary into CoreDocument system knowledge and surface it on the Discover layer dashboard.
- Wire a Vercel Cron heartbeat to invoke `syncGoogleConnectors` on a schedule (e.g. every 30 min) for autonomous monitoring.
- Add alerting: on any connector transitioning to failed/degraded, log an IntelFeed entry and flag for re-authorization.

## Acceptance Criteria
Invoking syncGoogleConnectors returns a status object listing all six connectors as 'connected' with valid refreshed tokens and non-null latency; a ConnectorHealth record is persisted per connector with a recent last_checked timestamp; the Vercel Cron job triggers the function on schedule and any degraded/failed connector produces an alert entry.
