## Summary
Verify and health-check the authorized Google Workspace connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and register them into the Discover layer data plane.

## Steps
- Load the stored OAuth credentials/tokens for each connected Google service from the secure secrets store
- Validate each token by issuing a lightweight authenticated probe (Drive: files.list?pageSize=1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: read a canary spreadsheet metadata; Tasks: tasklists.list; Search Console: sites.list)
- Refresh any expired access tokens using stored refresh tokens; flag connectors that fail refresh
- Persist a Connector health record (service, status, scopes, lastCheckedAt, expiresAt) into the Base44 entities / Supabase data store
- Register each healthy connector as an active Discover-layer data source with its capabilities and rate limits
- Emit a consolidated connector status report to CoreDocument and surface failures for re-authorization

## Acceptance Criteria
