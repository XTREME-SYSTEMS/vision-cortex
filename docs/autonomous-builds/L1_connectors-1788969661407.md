## Summary
Build a unified Google Workspace connector service that verifies and health-checks OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function 'googleConnectorManager' that centralizes OAuth token retrieval and refresh for all six Google services
- Store per-service OAuth scopes and connection status in a Supabase table 'google_connections' (service, status, scopes, last_verified, token_expiry)
- Implement token refresh logic using the stored Google refresh tokens, refreshing any expiring within 5 minutes
- For each service, perform a lightweight read probe: Drive files.list(pageSize=1), Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets metadata ping, Tasks tasklists.list, Search Console sites.list
- Record probe results (ok/failed + latency + error) back into 'google_connections' and emit a consolidated health report
- Expose the connector via the Discover layer so downstream DEEP state machines can request authenticated Google clients without re-authing
- Add error handling and retry (max 3, exponential backoff) plus structured logging to DeepRun for replayability

## Acceptance Criteria
Invoking googleConnectorManager returns a report where all six services (drive, calendar, gmail, sheets, tasks, searchConsole) show status 'ok' with valid non-expired tokens, the Supabase 'google_connections' table reflects the latest last_verified timestamps, and the run is logged in DeepRun with no unhandled errors.
