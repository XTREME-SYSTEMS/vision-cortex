## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that accepts a list of Google service connectors to validate.
- Load stored OAuth credentials/tokens for each connector from the Supabase external data store (zero-credit operation).
- For each service, perform a lightweight liveness probe: Drive (files.list limit=1), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets.get on a health-check sheet), Tasks (tasklists.list), Search Console (sites.list).
- Detect expired tokens and invoke the OAuth refresh flow, persisting refreshed tokens back to Supabase.
- Record each connector's status, latency, scopes, and last-checked timestamp into a Base44 entity `ConnectorHealth`.
- Emit a consolidated status report to CoreDocument/architecture Data Plane and log the run into DeepRun for replayability.
- Register a Vercel Cron heartbeat to invoke `googleConnectorSync` on a recurring interval for continuous monitoring.
- Follow coding standards: @/ alias imports, small focused files, lucide-react icons for any status UI.

## Acceptance Criteria
All six Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return a healthy status with valid non-expired tokens; a ConnectorHealth entity record exists per connector with status/latency/last-checked; expired tokens are auto-refreshed and persisted; a DeepRun log entry captures the run; and the Vercel Cron heartbeat is scheduled and triggers the function successfully.
