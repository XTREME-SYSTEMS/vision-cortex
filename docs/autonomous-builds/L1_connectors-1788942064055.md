## Summary
Build a unified Google Workspace connector service that verifies and manages OAuth-authorized connections to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console within the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorManager` (Deno/TypeScript) that centralizes Google Workspace OAuth token storage and refresh logic
- Store OAuth credentials and refresh tokens securely in Supabase table `google_connections` (columns: service, access_token, refresh_token, expiry, scopes, status)
- Implement per-service health-check calls: Drive files.list, Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets.get (test sheet), Tasks tasklists.list, Search Console sites.list
- Add automatic token refresh when access_token is within 5 minutes of expiry using the Google OAuth token endpoint
- Expose a `verifyConnections` action that pings all six services and returns a status map
- Log connection verification results to DeepRun execution logs for replayability
- Surface connection status to the Discover layer so downstream intelligence-gathering functions can query available data sources
- Add error handling and retry with backoff for transient Google API 429/5xx responses

## Acceptance Criteria
Invoking googleConnectorManager with action=verifyConnections returns status=connected for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), tokens auto-refresh before expiry, credentials persist in the Supabase google_connections table, and verification results are logged to DeepRun.
