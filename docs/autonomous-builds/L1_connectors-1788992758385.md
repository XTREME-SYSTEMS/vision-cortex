## Summary
Build a unified Google Workspace connector service that validates and orchestrates authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console for the Discover layer.

## Steps
- Create a Base44 backend function 'google_connector_sync' in Deno/TypeScript that reads OAuth credentials from Supabase secrets store
- Implement per-service client initializers for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console using the Google Workspace APIs
- Add scope validation to confirm each service has the required OAuth scopes and refresh tokens are valid
- Implement token refresh logic and persist refreshed tokens to Supabase for zero-credit reuse
- Expose normalized read methods (listFiles, listEvents, listMessages, readSheet, listTasks, querySearchAnalytics) that feed the Discover layer
- Register connector health status as a Base44 entity 'ConnectorStatus' with per-service last-sync timestamps and error states
- Wire the connector into the Vercel Cron heartbeat so each service is health-checked on the autonomous loop
- Log all sync runs to DeepRun for replayability and add structured error handling per service

## Acceptance Criteria
Invoking google_connector_sync returns a ConnectorStatus record showing all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with status 'connected', valid refreshed tokens persisted in Supabase, at least one successful normalized read per service, and a DeepRun log entry recorded; the Vercel cron heartbeat updates last-sync timestamps without errors.
