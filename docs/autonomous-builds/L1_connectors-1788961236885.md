## Summary
Build a unified Google Workspace connector service that verifies and persists authorized OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console into the Discover layer.

## Steps
- Define a GoogleConnector Base44 entity capturing service name, OAuth token references, scopes, connection status, and last-verified timestamp for each of the 6 services
- Create backend function to iterate over the 6 target services (drive, calendar, gmail, sheets, tasks, searchconsole) and perform a lightweight authorized health-check API call per service
- Store or refresh OAuth credentials in Supabase (zero-credit store) referencing Base44 entity IDs, never persisting raw tokens in plaintext
- Mark each service connection status as 'connected' or 'error' with diagnostic detail and update last-verified timestamp
- Register the connector outputs as a Discover-layer data source so downstream Understand/Predict layers can query them
- Emit a DeepRun execution log entry recording the connection verification result for replayability

## Acceptance Criteria
All six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' with a valid last-verified timestamp in the GoogleConnector entity, health-check API calls succeed for each, credentials are stored in Supabase without plaintext token exposure, and a DeepRun log entry confirms successful verification.
