## Summary
Build a unified Google Workspace connector health-check and orchestration function that verifies and registers the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors into the Discover layer.

## Steps
- Enumerate the six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and confirm OAuth scopes/tokens are stored securely in Supabase secrets store
- For each connector, perform a lightweight read probe (Drive: list 1 file; Calendar: list next event; Gmail: profile fetch; Sheets: metadata read; Tasks: list tasklists; Search Console: list sites) to validate live connectivity
- Persist a ConnectorRegistry entity in Base44 with fields: connector_name, status (connected/degraded/failed), scopes, last_verified_at, layer=1
- Wire each verified connector as a Discover-layer data source per the Intelligence Gathering Protocol, tagging outputs for Understand-layer consumption
- Emit a heartbeat log to DeepRun capturing verification results and register a Vercel Cron re-validation every 6 hours
- Surface a status dashboard component (<50 lines, lucide-react icons) showing per-connector health

## Acceptance Criteria
All six Google connectors return status 'connected' in the ConnectorRegistry entity, each passes its live read probe, a DeepRun heartbeat log is written, the 6-hour cron re-validation is registered, and the dashboard renders green status for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.
