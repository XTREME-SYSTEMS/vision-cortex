## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections into the Discover layer.

## Steps
- Enumerate the six authorized Google service connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) from stored OAuth credentials in Supabase
- For each connector, verify OAuth token validity and refresh expired tokens using the stored refresh_token
- Perform a lightweight canary API call per service (e.g. Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live access
- Record connector status (connected/degraded/failed), last_checked timestamp, and scopes into a Base44 ConnectorStatus entity
- Register each healthy connector as an active Discover-layer data source so downstream intelligence loops can consume it
- Emit a consolidated health report and log the run to DeepRun for replayability
- Schedule the health check on Vercel Cron heartbeat for continuous autonomous monitoring

## Acceptance Criteria
All six Google connectors return a status record with valid (non-expired) tokens, each canary API call succeeds (HTTP 200), ConnectorStatus entities are persisted with last_checked timestamps, connectors are registered as active Discover-layer sources, and a DeepRun log entry exists for the run.
