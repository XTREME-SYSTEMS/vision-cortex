## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections.

## Steps
- Enumerate authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) from the integration registry
- For each connector, validate stored OAuth credentials and refresh expired tokens using the stored refresh_token
- Perform a lightweight read probe per service (e.g. Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live access
- Record connector status (connected/degraded/failed), token expiry, and latency into a ConnectorHealth Base44 entity
- Emit a consolidated status report to CoreDocument/architecture Data Plane and surface failures to the Discover layer
- Schedule a Vercel Cron heartbeat to re-run this check every 15 minutes for autonomous monitoring

## Acceptance Criteria
All six connectors return status 'connected' with valid non-expired tokens and successful read probes, a ConnectorHealth record is persisted per service, and the Vercel Cron heartbeat is registered and firing on schedule.
