## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes OAuth for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create backend function `syncGoogleConnectors` in Base44 Deno/TypeScript that iterates over the six authorized Google services
- For each service, validate stored OAuth tokens and auto-refresh expired access tokens using the stored refresh token
- Perform a lightweight health-check API call per service (Drive: files.list limit 1, Calendar: calendarList.list, Gmail: users.getProfile, Sheets: spreadsheets ping, Tasks: tasklists.list, Search Console: sites.list)
- Persist connector status (connected/degraded/failed), last-checked timestamp, and scopes into a `ConnectorStatus` Base44 entity
- Log each check into DeepRun execution logs for replayability
- Expose aggregated status to the Discover layer so cloud browser and search flows can rely on live connectors
- Emit alerts/events for any connector in degraded or failed state

## Acceptance Criteria
Invoking syncGoogleConnectors returns a status object listing all six Google services as 'connected' with valid non-expired tokens, a ConnectorStatus entity is upserted per service with a fresh last-checked timestamp, and a DeepRun log entry is created; any failed refresh yields a 'failed' status and an emitted alert.
