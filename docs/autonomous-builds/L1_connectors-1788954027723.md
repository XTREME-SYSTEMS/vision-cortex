## Summary
Build a unified Google Workspace connector service that validates and manages OAuth credentials and health for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function that centralizes Google OAuth token storage, refresh, and scope validation for all six connected services
- Define a GoogleConnector entity to persist per-service connection status, granted scopes, token expiry, and last health-check timestamp
- Implement token refresh logic using stored refresh tokens, storing new access tokens in Supabase for zero-credit reuse
- Add per-service health probes: Drive (files.list limit=1), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets metadata read), Tasks (tasklists.list), Search Console (sites.list)
- Wire the connector into the Discover layer data-source registry so intelligence gathering can consume these services
- Register a Vercel Cron heartbeat entry to re-validate all connectors periodically and auto-heal expired tokens
- Emit structured status output (connected/degraded/failed per service) and persist to GoogleConnector entity

## Acceptance Criteria
Invoking googleWorkspaceConnector returns a status report showing all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) as 'connected', each with valid non-expired tokens and a successful health probe; GoogleConnector entity rows are persisted and the cron heartbeat successfully refreshes tokens without manual intervention.
