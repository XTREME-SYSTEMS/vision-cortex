## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes OAuth connectivity for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that centralizes access to all six Google services
- Load stored OAuth credentials per service from Supabase (zero-credit store) and validate token expiry, refreshing via Google OAuth refresh_token flow when needed
- For each service, perform a lightweight authenticated probe: Drive files.list(pageSize=1), Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets metadata read, Tasks tasklists.list, Search Console sites.list
- Record connector status (connected/degraded/failed), last_checked timestamp, scopes, and token_expiry into a Base44 entity `ConnectorStatus`
- Emit a normalized health summary object and log the run to DeepRun for replayability
- Expose results to the Discover layer so Google services are registered as active data sources
- Add error handling with retry/backoff and mark stale tokens for re-auth via a returned needs_reauth flag

## Acceptance Criteria
Invoking googleConnectorSync returns a status report where all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report 'connected' with valid non-expired tokens, a ConnectorStatus entity row is persisted per service with a recent last_checked timestamp, the run is logged in DeepRun, and any expired credentials are flagged needs_reauth=true rather than silently failing.
