## Summary
Build a unified Google Workspace connector service that validates and manages OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Supabase table 'google_connections' storing per-service OAuth tokens, scopes, refresh tokens, expiry, and connection status
- Implement a backend function that performs OAuth token exchange and refresh for each Google service using the Google Workspace integration credentials
- Add scope validation ensuring each of the 6 services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) has the required OAuth scopes granted
- Implement a health-check routine that pings each service's API (e.g., Drive files.list, Calendar events.list, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) and records status
- Persist connection status and last-verified timestamp per service into the google_connections table
- Expose a status summary endpoint returning the connected/degraded/failed state of all 6 connectors for the Discover layer
- Wire the connector health-check into the Vercel Cron heartbeat for periodic re-validation and token refresh

## Acceptance Criteria
All 6 Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' with valid non-expired tokens, each health-check API call succeeds, records are persisted in the google_connections table with a recent last-verified timestamp, and the status summary endpoint reports 6/6 connectors healthy.
