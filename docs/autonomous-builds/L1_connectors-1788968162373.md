## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that verifies and refreshes authorized connections (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `googleConnectorSync` (Deno/TypeScript) that iterates over the six authorized Google services.
- Load stored OAuth credentials per service from Supabase, validating token presence and scope coverage for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.
- For each service, perform a lightweight authenticated probe call (e.g. Drive: files.list?pageSize=1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata ping; Tasks: tasklists.list; Search Console: sites.list) to confirm live connectivity.
- Detect expired/near-expiry access tokens and refresh them via the stored refresh_token, persisting new tokens back to Supabase (zero-credit external store).
- Write a normalized connector status record to the Base44 `ConnectorStatus` entity with fields: service, connected(bool), scopes, last_checked, latency_ms, error.
- Emit a consolidated health summary to CoreDocument/architecture Data Plane log and surface failures to the Discover layer for autonomous re-auth flagging.
- Register a Vercel Cron heartbeat entry to invoke this sync every 6 hours for continuous Discover-layer freshness.

## Acceptance Criteria
Invoking googleConnectorSync returns connected=true for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with valid non-expired tokens, each probe returns HTTP 200 under 2000ms, ConnectorStatus entities are updated with a fresh last_checked timestamp, and the cron heartbeat is registered and firing on schedule.
