## Summary
Build a unified Google Workspace connector service that validates and manages OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console within the Discover layer.

## Steps
- Create a Base44 backend function `googleWorkspaceConnector` in Deno/TypeScript to centralize Google API auth and scope management
- Store OAuth credentials and refresh tokens securely in Supabase (zero-credit external store) keyed per service
- Implement token refresh logic with automatic re-auth for expired Google Workspace tokens
- Register each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with its required OAuth scopes and a health-check endpoint
- Add a connection-status verification routine that pings each Google API and records reachability into a `ConnectorStatus` Base44 entity
- Wire the connector into the Discover layer data sources so Council deliberation can query live Google data
- Expose a `getConnectorHealth` capability returning per-service status for monitoring via Vercel cron heartbeat
- Log all connection events to DeepRun execution logs for replayability

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return authenticated=true from getConnectorHealth, tokens auto-refresh without manual intervention, ConnectorStatus entity reflects live reachability, and connection events appear in DeepRun logs.
