## Summary
Build a unified Google Workspace connector layer that verifies and orchestrates authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console for the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorHub` that centralizes OAuth token retrieval and refresh for all six Google services
- Store and validate service credentials/scopes in Supabase (zero-credit store) with per-service status flags
- Implement per-service health-check calls (Drive files.list, Calendar calendarList, Gmail profile.get, Sheets spreadsheets.get, Tasks tasklists.list, Search Console sites.list)
- Normalize responses into a standard connector status schema {service, connected, scopes, lastChecked, error}
- Persist connector status to a Base44 entity `ConnectorStatus` for the Discover layer to consume
- Add token auto-refresh with retry and log failures to DeepRun execution logs
- Expose a `verify` action that returns aggregate readiness for all six services
- Follow technical standards: Deno/TypeScript backend, @/ imports, lucide-react for any status UI

## Acceptance Criteria
Calling googleConnectorHub with action 'verify' returns all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with connected=true, valid scopes, and no errors; ConnectorStatus entity reflects the same, and token refresh succeeds without manual intervention.
