## Summary
Build a unified Google Workspace connector service that validates and health-checks the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations.

## Steps
- Create a Base44 backend function `googleConnectorManager` that centralizes OAuth token retrieval and refresh for all six Google services
- Store connector credentials and scopes in a Supabase `google_connectors` table (service, status, scopes, token_expiry, last_health_check)
- Implement per-service health-check calls: Drive files.list, Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets.get on a probe sheet, Tasks tasklists.list, Search Console sites.list
- Normalize each health-check into a status object {service, connected: bool, scopes, error}
- Persist health-check results to the Supabase table and emit a consolidated readiness report to CoreDocument
- Add a Vercel cron entry to invoke `googleConnectorManager` on a heartbeat to auto-refresh expiring tokens
- Expose a React status panel (small focused components, lucide-react icons) surfacing each connector's live state

## Acceptance Criteria
Invoking googleConnectorManager returns connected:true for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with valid non-expired tokens, results are persisted in the Supabase google_connectors table, and the cron heartbeat successfully refreshes tokens before expiry.
