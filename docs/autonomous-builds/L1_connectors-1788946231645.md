## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes OAuth access for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function that iterates over the six authorized Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console)
- For each service, verify stored OAuth tokens exist and refresh expired access tokens using the stored refresh token
- Perform a lightweight read probe per service (e.g. Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live connectivity
- Record each service's status, scope, latency, and last-checked timestamp into a Base44 GoogleConnector entity
- Emit a consolidated connector health record and flag any service needing re-authorization
- Register the function on Vercel Cron for periodic heartbeat re-validation (Discover layer)
- Log the run to DeepRun for replayability per DEEP protocol

## Acceptance Criteria
All six Google services return a live 200 probe with valid refreshed tokens, a GoogleConnector health record is persisted for each with status='connected', any failures are flagged with re-auth reason, and the run appears in DeepRun logs.
