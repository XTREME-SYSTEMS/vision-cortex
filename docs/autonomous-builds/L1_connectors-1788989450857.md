## Summary
Build a unified Google Workspace connector health-check and integration layer that validates and orchestrates the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors for the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorManager` (Deno/TypeScript) that centralizes OAuth token retrieval and refresh for all six Google services
- Implement per-service health probes: Drive (files.list), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets.get on a probe sheet), Tasks (tasklists.list), Search Console (sites.list)
- Store connector status, scopes, last-checked timestamp, and token expiry in a Supabase table `google_connector_status` for zero-credit reads
- Normalize each service response into a common ConnectorHealth shape { service, connected, scopes, latencyMs, error }
- Wire the manager into the Discover layer so Search Console SEO data and Drive documents feed the intelligence pipeline
- Add a Vercel Cron heartbeat entry to invoke the health check on a schedule and persist results
- Expose a summary endpoint returning aggregate connector health for dashboard display
- Log all runs to DeepRun for replayability per DEEP protocol

## Acceptance Criteria
All six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return connected=true with valid scopes and latency recorded; status rows persist in Supabase google_connector_status; token refresh succeeds automatically on expiry; cron heartbeat updates statuses on schedule; a DeepRun log entry is created per invocation and the summary endpoint reports 6/6 healthy.
