## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections.

## Steps
- Enumerate all authorized Google Workspace connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) from the integrations registry
- For each connector, validate OAuth token validity and refresh expired tokens via the stored refresh_token
- Perform a lightweight read probe per service (e.g., Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live connectivity
- Persist connector status (connected/degraded/failed), scopes granted, and last-checked timestamp to a Base44 entity (e.g., ConnectorHealth)
- Emit a normalized health summary into the Discover layer so intelligence loops can rely on these data sources
- Log the full check run to DeepRun for replayability and schedule a recurring Vercel Cron heartbeat to re-validate

## Acceptance Criteria
All six Google Workspace connectors return status 'connected' with valid non-expired tokens, each read probe succeeds, a ConnectorHealth record is written with a recent last-checked timestamp for every service, and the run is logged to DeepRun with a scheduled cron re-validation.
