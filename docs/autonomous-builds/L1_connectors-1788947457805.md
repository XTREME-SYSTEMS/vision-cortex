## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes all authorized core infrastructure connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `syncGoogleConnectors` in Deno/TypeScript that iterates over the six authorized Google scopes.
- For each connector, retrieve stored OAuth credentials from Supabase and verify token validity; refresh expired access tokens using the stored refresh token.
- Ping each Google API endpoint with a lightweight read call (Drive: files.list?pageSize=1, Calendar: calendarList.list, Gmail: users.getProfile, Sheets: spreadsheets metadata, Tasks: tasklists.list, Search Console: sites.list) to confirm live connectivity.
- Record connector status (connected / degraded / failed), last-checked timestamp, and scope coverage into a `ConnectorHealth` Base44 entity.
- Emit a consolidated health report to the Discover layer so downstream intelligence gathering can rely on verified data sources.
- Add a Vercel Cron heartbeat entry to re-run the sync every 30 minutes for autonomous credential refresh.
- Log the run to DeepRun for replayability and surface failures to the Council for remediation.

## Acceptance Criteria
All six connectors return a 'connected' status with valid (non-expired) tokens, a ConnectorHealth record is persisted per connector with a fresh last-checked timestamp, the consolidated report is available to the Discover layer, and the Vercel Cron job is registered and executes successfully at least once.
