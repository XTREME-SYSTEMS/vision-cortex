## Summary
Build a unified Google Workspace connector service that verifies and health-checks OAuth access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorManager` in Deno/TypeScript that centralizes OAuth token retrieval and refresh for all Google Workspace scopes
- Define required OAuth scopes for each service: drive.readonly/file, calendar, gmail.readonly/send, spreadsheets, tasks, webmasters.readonly
- Implement per-service health-check probes (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: dummy spreadsheet metadata get; Tasks: tasklists.list; Search Console: sites.list)
- Persist connection status, granted scopes, token expiry, and last-checked timestamp to a `GoogleConnection` Base44 entity
- Handle token refresh automatically and log failures to DeepRun execution logs
- Return a consolidated status report for all six services
- Wire a Vercel Cron heartbeat to re-run health checks every 6 hours and flag disconnected services

## Acceptance Criteria
Invoking googleConnectorManager returns a status object where all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report connected:true with valid non-expired tokens and their probe calls succeed; the GoogleConnection entity is populated with per-service scopes and last-checked timestamps, and the cron heartbeat re-verifies status without manual intervention.
