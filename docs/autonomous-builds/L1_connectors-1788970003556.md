## Summary
Build a unified Google Workspace connector health-check and token-refresh service that verifies and maintains authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorManager` (Deno/TypeScript) that centralizes OAuth token storage and refresh for all six Google services
- Store per-service credentials and scopes in a `GoogleConnector` Base44 entity (service name, scopes, access_token, refresh_token, expiry, status, last_checked)
- Implement token refresh logic using the Google OAuth2 refresh endpoint, updating expiry and access_token when within 5 minutes of expiration
- Add a lightweight per-service ping (Drive files.list?pageSize=1, Calendar calendarList, Gmail getProfile, Sheets spreadsheets.get on a test sheet, Tasks tasklists.list, Search Console sites.list) to confirm live connectivity
- Record each check result into the entity and emit a consolidated status report to CoreDocument/architecture Data Plane log
- Wire a Vercel Cron heartbeat to invoke `googleConnectorManager` every 30 minutes for autonomous health maintenance
- Expose a `mode` parameter: 'verify' for read-only ping, 'refresh' to force token refresh, 'report' to return current status of all connectors

## Acceptance Criteria
Invoking googleConnectorManager returns status 'connected' for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with valid non-expired tokens; each service ping succeeds, the GoogleConnector entity reflects last_checked timestamps within the current run, and the Vercel Cron heartbeat is confirmed scheduled at 30-minute intervals.
