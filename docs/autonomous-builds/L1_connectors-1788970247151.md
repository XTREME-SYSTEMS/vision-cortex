## Summary
Build a unified Google Workspace connector health-check and token-refresh service that validates all authorized core infrastructure connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `google_connector_manager` that centralizes OAuth token storage and refresh for all six Google services
- Read stored refresh tokens from Supabase table `google_credentials` and refresh access tokens via Google OAuth token endpoint when expired
- For each connector (drive, calendar, gmail, sheets, tasks, searchconsole) perform a lightweight scope-validated ping (e.g. drive.about.get, calendar.calendarList.list, gmail.users.getProfile, sheets metadata read, tasks.tasklists.list, searchconsole.sites.list)
- Persist a `connector_status` record per service in Supabase with fields: service, status, scopes, last_checked, error
- Expose the aggregated health report to the Discover layer so Google services are marked available as data sources
- Wire a Vercel cron heartbeat to invoke this function hourly to keep tokens fresh and status current
- Log execution to DeepRun for replayability and emit alerts on any degraded connector

## Acceptance Criteria
Invoking google_connector_manager returns a report where all six services (drive, calendar, gmail, sheets, tasks, searchconsole) show status 'connected' with valid non-expired access tokens and correct scopes; connector_status rows are updated in Supabase; the hourly cron runs without errors and any failed connector produces a logged alert in DeepRun.
