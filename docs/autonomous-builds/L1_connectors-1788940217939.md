## Summary
Build a unified Google Workspace connector service that validates and exposes authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console for the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorSync` (Deno/TypeScript) that centralizes OAuth token management for all Google services
- Store and refresh OAuth credentials in Supabase table `google_connections` (service, access_token, refresh_token, scopes, expires_at, status)
- Implement per-service health-check probes: Drive (files.list), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets.get on a test sheet), Tasks (tasklists.list), Search Console (sites.list)
- Add automatic token refresh logic using the refresh_token when expires_at is near
- Expose normalized connector status to the Discover layer data plane and log results to DeepRun for replayability
- Register a Vercel Cron heartbeat to re-validate all six connectors every 15 minutes and flag any degraded connection
- Emit a consolidated connector status entity readable by the Understand layer for scenario grounding

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' from their health-check probes, tokens auto-refresh before expiry, results are persisted to Supabase `google_connections` and logged to DeepRun, and the Vercel Cron heartbeat successfully re-validates every 15 minutes.
