## Summary
Verify and harden the authorized Google Workspace connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) into a unified, health-monitored connector registry within the Discover layer.

## Steps
- Enumerate all six authorized Google OAuth scopes (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and confirm stored refresh tokens are valid and non-expired
- Create or update a Base44 entity 'ConnectorRegistry' recording each connector's status, scopes, last_health_check, and token_expiry
- Implement per-connector health-check probes: Drive files.list, Calendar calendarList, Gmail profile get, Sheets spreadsheets metadata, Tasks tasklists list, Search Console sites list
- Wire connector health results into the Discover-layer Data Sources so downstream intelligence gathering can query availability
- Add a Vercel Cron heartbeat entry to re-run connector health checks hourly and auto-refresh tokens nearing expiry
- Log all probe results to DeepRun execution logs and surface a consolidated status dashboard field
- Emit alerts to CoreDocument/system-status when any connector transitions to degraded or disconnected

## Acceptance Criteria
ConnectorRegistry entity shows all six Google connectors with status='connected', valid non-expired tokens, and a successful last_health_check timestamp within the last hour; each probe returns HTTP 200; the hourly cron job runs without error and DeepRun logs record each health check as passed.
