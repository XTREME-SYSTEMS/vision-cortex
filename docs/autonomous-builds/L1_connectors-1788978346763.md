## Summary
Build a unified Google Workspace connector service that verifies and manages OAuth-authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console for the Discover layer.

## Steps
- Create a Base44 backend function `googleWorkspaceConnector` (Deno/TypeScript) that centralizes OAuth token retrieval, refresh, and scope validation for all six Google services
- Store and rotate OAuth refresh tokens securely in Supabase table `google_connections` (columns: service, account_email, refresh_token, scopes, status, last_verified_at)
- Implement per-service health-check calls: Drive (files.list), Calendar (calendarList.list), Gmail (users.getProfile), Sheets (spreadsheets.get on a probe sheet), Tasks (tasklists.list), Search Console (sites.list)
- Add token-refresh logic using the Google OAuth2 token endpoint, updating Supabase on refresh
- Emit a connection status report entity in Base44 recording each service's connected/expired/error state
- Register the connector as a Discover-layer data source and expose a `verifyConnections` action for the Vercel cron heartbeat
- Log each verification run to DeepRun for replayability

## Acceptance Criteria
All six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' from a single verifyConnections invocation, tokens auto-refresh without manual intervention, and a status report is persisted to Base44 with a corresponding DeepRun log entry.
