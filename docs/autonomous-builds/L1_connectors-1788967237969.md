## Summary
Build a unified Google Workspace connector service that validates and exposes authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections to the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorSync` that reads stored OAuth credentials for the connected Google account from Supabase
- Validate active OAuth scopes for each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and refresh tokens where expired
- Instantiate authenticated API clients for each of the six Google services using the refreshed access token
- Perform a lightweight health-check call per service (e.g. Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list)
- Persist a connector status record per service (connected, scopes, lastChecked, health) into a Base44 `IntegrationStatus` entity
- Expose the aggregated connector state to the Discover layer data sources registry so intelligence loops can consume Google Workspace data
- Emit a DeepRun execution log entry recording the sync outcome for replayability

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return a health-check status of 'connected' with valid non-expired tokens, an IntegrationStatus record exists per service with lastChecked timestamp, and a DeepRun log entry confirms a successful sync accessible to the Discover layer.
