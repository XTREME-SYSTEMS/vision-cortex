## Summary
Build a unified Google Workspace connector service that validates and health-checks the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console integrations, persisting connection status to the data plane.

## Steps
- Create a Base44 backend function `googleConnectorSync` (Deno/TypeScript) that accepts a list of Google service scopes to validate
- Load stored OAuth credentials/refresh tokens from Supabase for the connected Google Workspace account
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight read-only probe call (e.g. Drive: files.list?pageSize=1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata; Tasks: tasklists.list; Search Console: sites.list)
- Refresh expired access tokens automatically via the OAuth refresh flow and re-persist tokens to Supabase
- Record per-service connection status (connected/degraded/failed), scopes granted, last-checked timestamp, and error detail into a Base44 `IntegrationStatus` entity
- Expose the aggregated health result so the Discover layer can gate Google-dependent data source usage
- Register the function on a Vercel cron heartbeat to re-verify connectors periodically

## Acceptance Criteria
Invoking googleConnectorSync returns a status object listing all six Google services each marked 'connected' with valid non-expired tokens, an IntegrationStatus record is written to the data plane with a fresh last-checked timestamp, and any expired token is transparently refreshed without manual re-auth.
