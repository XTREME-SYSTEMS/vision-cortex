## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that reads stored OAuth credentials for each Google service from Supabase.
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authenticated ping (e.g., Drive files.list?pageSize=1, Calendar calendarList, Gmail getProfile, Sheets spreadsheets.get metadata, Tasks tasklists.list, Search Console sites.list).
- Detect expired access tokens and automatically refresh them using the stored refresh_token against Google's OAuth2 token endpoint; persist new tokens back to Supabase.
- Record each connector's status (connected, expired, error) with timestamp and latency into a Supabase `connector_health` table for zero-credit auditing.
- Return a consolidated health report and surface any connectors requiring re-authorization.
- Wire the function into a Vercel Cron heartbeat to run periodic health checks (e.g., every 30 minutes).
- Follow technical standards: @/ import alias, lucide-react icons for any UI status badge, small focused files.

## Acceptance Criteria
Invoking googleConnectorSync returns a report where all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report status 'connected', expired tokens are auto-refreshed and persisted to Supabase, and a corresponding row is written to the connector_health table with timestamp and latency for each service.
