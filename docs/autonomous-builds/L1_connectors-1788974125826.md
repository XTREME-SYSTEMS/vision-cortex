## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes authorized connections to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that reads stored OAuth credentials for the connected Google account.
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), issue a lightweight authenticated probe call to confirm scope validity and token freshness.
- Detect expired access tokens and perform refresh_token exchange against Google OAuth2 token endpoint; persist refreshed tokens to Supabase `google_credentials` table (zero-credit store).
- Record per-service connection status, granted scopes, last-verified timestamp, and any error into a Base44 `ConnectorStatus` entity.
- Expose an aggregated health object so the Discover layer can query which Google data sources are live before scheduling scrapes/queries.
- Register a Vercel Cron heartbeat to invoke `googleConnectorSync` on an interval to keep tokens warm and status current.
- Emit a DeepRun log entry documenting the validation run for replayability.

## Acceptance Criteria
Invoking googleConnectorSync returns a status object where all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report connected=true with valid non-expired tokens; expired tokens are auto-refreshed and persisted to Supabase; a ConnectorStatus entity and DeepRun log are written, and the Vercel Cron heartbeat is registered.
