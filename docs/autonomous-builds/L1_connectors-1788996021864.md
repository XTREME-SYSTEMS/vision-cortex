## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that verifies and refreshes OAuth tokens for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that reads stored OAuth credentials for each Google service from the Supabase `google_connections` table
- Implement per-service token validation: check expiry, and if expired, refresh using the stored refresh_token against Google's OAuth token endpoint
- Persist refreshed access_token, expiry, and last_verified timestamp back to Supabase for each connector
- For each connected service, perform a lightweight liveness probe (Drive: files.list?pageSize=1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: drive files filtered to spreadsheet mimeType; Tasks: tasklists.list; Search Console: sites.list)
- Aggregate results into a status report per connector (connected | expired_refreshed | error) with error detail
- Write a summary record to the Base44 `ConnectorStatus` entity and log the run to DeepRun
- Schedule the function on Vercel Cron to run hourly as part of the Discover-layer heartbeat
- Expose the aggregated status to the Discover layer so downstream intelligence functions know which sources are live

## Acceptance Criteria
Invoking googleConnectorSync returns a JSON report listing all six Google services each with status 'connected' or 'expired_refreshed', no 'error' entries, the ConnectorStatus entity is updated with a fresh last_verified timestamp, a DeepRun log entry is created, and the Vercel Cron job is registered to run hourly.
