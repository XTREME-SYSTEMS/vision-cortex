## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that verifies and refreshes authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Define a GoogleConnector entity in Base44 to track each service (service_name, auth_status, token_expiry, last_sync, scopes, error_state).
- Implement OAuth token validation and refresh logic using stored refresh tokens for each of the six Google services.
- Create a health-check routine that pings each API endpoint (Drive files.list, Calendar events.list, Gmail profile.get, Sheets spreadsheets.get, Tasks tasklists.list, Search Console sites.list) and records reachability.
- Persist connector status to Supabase for zero-credit read operations and update Base44 GoogleConnector entities.
- Wire the orchestrator into the Discover layer so downstream state machines can query live connector availability.
- Register a Vercel Cron heartbeat to re-run the health-check every 6 hours and auto-refresh expiring tokens.
- Emit a DeepRun log entry summarizing connector states and any remediation actions taken.

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return auth_status 'connected' with valid non-expired tokens, each health-check API call succeeds, GoogleConnector entities and Supabase records reflect current status, and a DeepRun log confirms a successful sync cycle triggered by cron.
