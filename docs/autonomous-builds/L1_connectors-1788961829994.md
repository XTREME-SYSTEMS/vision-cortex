## Summary
Build a unified Google Workspace connector health-check and orchestration function that verifies and normalizes access across Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorOrchestrator` in Deno/TypeScript that accepts a list of target Google services
- Load OAuth credentials/tokens from Supabase secure store, refreshing expired tokens via the Google OAuth2 token endpoint
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authenticated probe call (e.g., Drive files.list?pageSize=1, Calendar calendarList, Gmail getProfile, Sheets spreadsheets.get, Tasks tasklists.list, Search Console sites.list)
- Normalize each probe result into a status object {service, connected, scopes, latency_ms, error}
- Persist connector status to a Base44 entity `ConnectorStatus` and log the run to DeepRun
- Emit a consolidated health summary into CoreDocument/architecture Data Sources section so Discover layer can query available connectors
- Return the aggregated status array and an overall healthy/degraded flag

## Acceptance Criteria
Invoking googleConnectorOrchestrator returns connected:true for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) with valid non-expired tokens, a ConnectorStatus entity row is written per service, a DeepRun log entry exists, and the overall flag reads 'healthy'.
