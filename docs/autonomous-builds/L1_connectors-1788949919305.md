## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and normalizes the newly authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections into the Discover layer.

## Steps
- Enumerate all authorized Google Workspace scopes and verify OAuth tokens are stored and refreshable for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console
- Create a GoogleConnector Base44 entity to persist per-service connection status, last_sync timestamp, scope list, and error state
- Implement a health-check routine that pings each service's minimal read endpoint (e.g., Drive files.list, Calendar events.list, Gmail profile, Sheets metadata, Tasks tasklists.list, Search Console sites.list) and records latency + status
- Normalize each service response into a common ConnectorStatus schema {service, connected, scopes, last_checked, latency_ms, error}
- Register the connector outputs as Discover-layer data sources so downstream Understand/Predict layers can consume them
- Add token auto-refresh with retry/backoff and write failures to the connector error state for Vercel Cron monitoring
- Expose an aggregate readiness flag (all_connected) surfaced to the system dashboard

## Acceptance Criteria
Invoking syncGoogleConnectors returns a 200 with a per-service status array where Drive, Calendar, Gmail, Sheets, Tasks, and Search Console each report connected=true, valid refreshable tokens, non-null last_checked, and all_connected=true; failures are persisted to the GoogleConnector entity with actionable error messages.
