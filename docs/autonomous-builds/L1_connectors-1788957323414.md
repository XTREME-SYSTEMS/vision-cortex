## Summary
Build a unified Google Workspace connector health-check and orchestration function that validates and manages authorized connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `googleConnectorOrchestrator` that reads stored OAuth credentials for each Google service from Supabase.
- For each connector (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight validation call (e.g., Drive files.list limit 1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list).
- Implement automatic token refresh using the stored refresh_token when a 401 is returned, persisting new access tokens to Supabase (zero-credit store).
- Record connector status (connected/degraded/failed), last_checked timestamp, and scope coverage into a `ConnectorStatus` Base44 entity.
- Expose a normalized response object summarizing each connector's health and any remediation needed (re-auth link).
- Wire the function into the Vercel Cron heartbeat to run periodic health checks and emit alerts on failure.
- Follow Technical Standards: Deno/TypeScript backend, @/ imports, small focused modules, lucide-react icons for any status UI.

## Acceptance Criteria
Invoking googleConnectorOrchestrator returns a status object where all six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report 'connected', tokens auto-refresh on expiry, ConnectorStatus entities are updated with fresh timestamps, and the cron job runs without errors.
