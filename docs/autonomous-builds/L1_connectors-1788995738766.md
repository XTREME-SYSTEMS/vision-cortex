## Summary
Build a unified Google Workspace connector health-check and normalization layer that verifies and standardizes access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console for the Discover layer.

## Steps
- Enumerate all authorized Google service scopes (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and confirm OAuth tokens are stored and refreshable
- Create a Base44 backend function that performs a lightweight ping/read against each Google service to validate live connectivity
- Normalize each service response into a common GoogleConnectorStatus entity with fields: service, connected, scopes, last_checked, latency_ms, error
- Persist connector status to Supabase for zero-credit reads by the Discover layer
- Wire the health-check into the Vercel Cron heartbeat to run on the autonomous loop interval
- Expose a summary aggregate (overall_healthy boolean) consumed by the Discover layer intelligence sources
- Log any failed connectors to DeepRun with actionable re-auth instructions

## Acceptance Criteria
Invoking verifyGoogleConnectors returns a status object listing all six Google services with connected=true, valid scopes, and latency recorded; GoogleConnectorStatus rows are persisted to Supabase; overall_healthy=true; and the cron heartbeat triggers periodic re-checks with failures logged to DeepRun.
