## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that verifies and refreshes authorized connections to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` (Deno/TypeScript) that iterates over the six authorized Google services
- For each service, validate the stored OAuth token, refresh it via the Google token endpoint if expired, and persist updated credentials to Supabase
- Perform a lightweight authorized read per service (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata ping; Tasks: tasklists.list; Search Console: sites.list) to confirm live connectivity
- Record per-service status (connected, token_expiry, last_checked, error) into a Supabase `connector_status` table for zero-credit reads
- Emit a consolidated health report to CoreDocument and log the run into DeepRun for replayability
- Expose the report to the Discover layer so downstream intelligence loops can rely on connector availability
- Add Vercel Cron heartbeat entry to invoke `googleConnectorSync` on a recurring schedule for autonomous monitoring

## Acceptance Criteria
Invoking googleConnectorSync returns HTTP 200 with a report where all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) show status 'connected' with valid non-expired tokens, a corresponding row per service exists in the Supabase connector_status table with a recent last_checked timestamp, and a DeepRun execution log entry is persisted for the run.
