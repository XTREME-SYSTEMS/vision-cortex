## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes all authorized Google service integrations (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `googleConnectorSync` in Deno/TypeScript that centralizes OAuth token handling for all six Google services
- Load stored OAuth credentials per service from Supabase, checking token expiry and refreshing via the Google OAuth token endpoint where needed
- For each service, execute a lightweight liveness probe: Drive files.list(pageSize=1), Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets metadata read, Tasks tasklists.list, Search Console sites.list
- Record per-service status (connected/degraded/failed), last-checked timestamp, and refreshed token metadata into a Supabase `google_connector_status` table for zero-credit reads
- Emit a consolidated health summary to CoreDocument/DiscoverLayer feed so the Discover layer knows which data sources are available
- Add retry-with-backoff and structured error logging to DeepRun execution logs for any probe failure
- Expose the aggregated status via a read endpoint for the frontend connector dashboard using @/ aliased imports and lucide-react icons

## Acceptance Criteria
Invoking googleConnectorSync returns a 200 response with a status object listing all six Google services each marked 'connected', expired tokens are automatically refreshed and persisted to Supabase, the google_connector_status table reflects current timestamps, and any failed probe is logged to DeepRun with a clear error reason.
