## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes all authorized Google service integrations (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function 'googleConnectorSync' in Deno/TypeScript that reads stored OAuth credentials for each Google service from Supabase.
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authenticated ping (e.g., Drive files.list?pageSize=1, Calendar calendarList.list, Gmail profile.get, Sheets metadata, Tasks tasklists.list, Search Console sites.list) to verify token validity.
- Detect expired access tokens and refresh them using the stored refresh_token via the Google OAuth token endpoint; persist new tokens back to Supabase.
- Record per-connector status (connected, degraded, expired, error), last_checked timestamp, and scopes into a Base44 'ConnectorStatus' entity.
- Emit a consolidated health report to the Discover layer so downstream state machines know which data sources are live.
- Log the run into DeepRun for replayability and schedule recurring validation via Vercel Cron heartbeat.
- Return a structured summary of all connector statuses to the caller.

## Acceptance Criteria
Invoking googleConnectorSync returns a status object listing all six Google services each marked 'connected' with a valid recent last_checked timestamp; expired tokens are automatically refreshed and persisted; ConnectorStatus entities are updated in Supabase; and a DeepRun log entry exists for the execution.
