## Summary
Build a unified Google Workspace connector health-check and orchestration function that verifies and standardizes access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` that reads OAuth credentials/tokens for the Google Workspace integration from the secure store
- Validate each service scope (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) by making a lightweight read call per API and capturing status
- Auto-refresh expired OAuth tokens and persist refreshed tokens back to the credential store
- Normalize each service response into a ConnectorStatus entity record (service, scope, status, last_checked, error)
- Log the sync run to DeepRun for replayability and emit a consolidated health summary
- Expose the connector statuses to the Discover layer so cloud browser and search components can consume Google data sources
- Schedule the function on Vercel Cron heartbeat to run periodically and re-validate connectors

## Acceptance Criteria
Function returns a 200 with a status object listing all six Google services as 'connected', ConnectorStatus entities are persisted with recent last_checked timestamps, expired tokens are auto-refreshed, and a DeepRun log entry is created for the sync run.
