## Summary
Build a unified Google Workspace connector health-check and orchestration function that validates and surfaces authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorsSync` in Deno/TypeScript that reads stored OAuth tokens for the connected Google account
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authenticated probe call (e.g. Drive files.list?pageSize=1, Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets metadata, Tasks tasklists.list, Search Console sites.list)
- Refresh expired access tokens via the Google OAuth refresh_token flow and persist updated tokens to the Supabase `google_credentials` store (zero-credit operation)
- Record per-service connection status, scopes granted, last-check timestamp, and any error into a `ConnectorStatus` Base44 entity
- Expose the aggregated status to the Discover layer so downstream DEEP state machines can query which connectors are live
- Add a Vercel Cron heartbeat entry to invoke `googleConnectorsSync` on a recurring interval for continuous health monitoring
- Log the run to DeepRun for replayability and emit alerts on any service returning an auth failure

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' in the ConnectorStatus entity with valid non-expired tokens, the cron heartbeat runs successfully, and a DeepRun log records the sync with zero auth errors.
