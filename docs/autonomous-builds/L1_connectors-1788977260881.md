## Summary
Build a unified Google Workspace connector health-check and token-refresh service that verifies and maintains authorized access to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` that reads stored OAuth credentials for each Google service from Supabase (zero-credit store)
- For each connector (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), perform a lightweight authenticated ping to validate the access token scope and connectivity
- Detect expired or near-expiry access tokens and refresh them using the stored refresh_token via Google OAuth token endpoint
- Persist refreshed tokens and updated expiry timestamps back to Supabase, and write a connector status record to a Base44 `ConnectorStatus` entity
- Emit a consolidated health report (per-service: connected|degraded|failed, scopes, last_checked) for the Discover layer to consume
- Schedule the function on Vercel Cron heartbeat to run periodically so connectors stay live for autonomous loops
- Log the run to DeepRun for replayability and surface any failures to the Council/Understand layer

## Acceptance Criteria
Running googleConnectorSync returns status 'connected' for all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console), refreshes any expiring tokens, persists updated tokens and a ConnectorStatus record to Supabase, and logs a replayable DeepRun entry with a per-service health report.
