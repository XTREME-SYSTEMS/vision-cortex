## Summary
Build a unified Google Workspace connector service that verifies and health-checks authorized OAuth scopes for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console, persisting connection status to Base44 entities.

## Steps
- Create a GoogleConnector Base44 entity to persist per-service connection status (service name, scopes, token_valid, last_checked, last_error).
- Implement OAuth token retrieval and refresh logic using stored Google Workspace credentials, handling expiry via refresh_token grant.
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) perform a lightweight read-only health probe: Drive files.list(pageSize=1), Calendar calendarList.list, Gmail users.getProfile, Sheets spreadsheets.get on a probe sheet, Tasks tasklists.list, Search Console sites.list.
- Record each probe result (ok/failed, latency, error) into the GoogleConnector entity.
- Expose an aggregated status object indicating all six connectors are healthy and the granted scope set.
- Log the connection audit to DeepRun execution logs and emit a heartbeat-compatible summary for Vercel Cron monitoring.
- Return a consolidated report and surface any scope gaps or token failures for remediation.

## Acceptance Criteria
Invoking connectGoogleWorkspace returns a report where all six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) show token_valid=true and probe status=ok, the GoogleConnector entity is populated with fresh last_checked timestamps, and a DeepRun log entry records the successful health check with no scope gaps.
