## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes all authorized core infrastructure connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `syncCoreConnectors` in Deno/TypeScript that iterates over the six authorized Google connectors.
- For each connector, verify OAuth token validity and refresh expired tokens using the stored refresh token from the Google Workspace integration.
- Perform a lightweight canary call per service (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata ping; Tasks: tasklists.list; Search Console: sites.list) to confirm live connectivity.
- Record each connector's status, latency, scopes, and last-verified timestamp into a Base44 `ConnectorStatus` entity (create the entity if absent).
- Emit a consolidated health report to CoreDocument and log the run to DeepRun for replayability.
- Register a Vercel Cron heartbeat to invoke `syncCoreConnectors` every 6 hours for autonomous re-validation.
- Return a structured summary with per-connector pass/fail and overall readiness flag.

## Acceptance Criteria
All six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' with a valid refreshed token and successful canary call; a ConnectorStatus record is persisted per connector with last-verified timestamp, a DeepRun log entry exists for the run, and the cron job is registered and fires on schedule.
