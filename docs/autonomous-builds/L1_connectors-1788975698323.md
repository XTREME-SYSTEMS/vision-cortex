## Summary
Build a unified Google Workspace connector health verification and status registry that confirms Drive, Calendar, Gmail, Sheets, Tasks, and Search Console are authorized and operational.

## Steps
- Create a Base44 backend function 'verifyGoogleConnectors' that iterates over each Google service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console)
- For each service, perform a lightweight read-only probe using the stored OAuth credentials (e.g. Drive files.list limit 1, Calendar calendarList, Gmail profile.get, Sheets metadata read, Tasks tasklists.list, Search Console sites.list)
- Capture per-service status: connected boolean, scope list, token expiry, and last error message if any
- Refresh OAuth tokens automatically when expiry is within threshold and persist refreshed tokens to the credentials store
- Upsert results into a 'ConnectorStatus' Supabase table (zero-credit) with service name, status, scopes, checked_at timestamp
- Expose an aggregated health object to the Discover layer so connectors register as available data sources
- Log the run to DeepRun with a replayable execution record and score based on connectors healthy vs total
- Schedule the verification via Vercel Cron heartbeat to run periodically and alert on any degraded connector

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return connected=true with valid non-expired tokens; ConnectorStatus records are upserted in Supabase with recent checked_at timestamps; a DeepRun log records the run with a health score of 6/6; the Discover layer lists all six as available data sources; cron schedule is active and any degraded connector triggers an alert.
