## Summary
Build a unified Google Workspace connector service that validates and health-checks all authorized Google integrations (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) into the Discover layer.

## Steps
- Create a Base44 backend function `googleConnectorHealthCheck` that iterates over each authorized Google service scope
- For each service, perform a lightweight read-only API call (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: labels.list; Sheets: spreadsheets metadata ping; Tasks: tasklists.list; Search Console: sites.list) to verify token validity
- Store connection status, last-checked timestamp, granted scopes, and token expiry per service in a Base44 entity `GoogleConnector`
- Auto-refresh OAuth tokens via stored refresh tokens when expiry is within 5 minutes; log refresh events to DeepRun
- Register each verified service as an active Data Source in the Discover layer registry so downstream intelligence loops can query them
- Surface aggregated connector health in a dashboard component `GoogleConnectorStatus.jsx` (lucide-react icons, <50 lines, @/ imports, default export)
- Wire a Vercel Cron heartbeat to invoke the health check every 15 minutes and alert on any degraded/expired connector

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' with valid non-expired tokens in the GoogleConnector entity, each is registered as an active Discover-layer data source, the cron heartbeat runs every 15 minutes, and the GoogleConnectorStatus dashboard renders live green status for all six with correct last-checked timestamps.
