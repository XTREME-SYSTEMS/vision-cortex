## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections.

## Steps
- Enumerate the six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) from the integration registry
- For each connector, verify stored OAuth credentials exist and are non-expired; trigger token refresh via the Google OAuth refresh endpoint when needed
- Perform a minimal read probe per service (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets metadata; Tasks: tasklists.list; Search Console: sites.list) to confirm live connectivity
- Persist connector status (connected/degraded/failed), last-checked timestamp, scopes, and probe latency into a GoogleConnector Base44 entity / Supabase table
- Emit a consolidated connectivity report into the Discover layer intel feed and flag any failed connector for re-authorization
- Register a Vercel cron heartbeat to re-run the health check on a scheduled interval for autonomous monitoring

## Acceptance Criteria
All six Google Workspace connectors return a 'connected' status with valid refreshed tokens, each read probe succeeds, connector status records are persisted with current timestamps, and the consolidated report appears in the Discover layer with no connectors flagged as failed.
