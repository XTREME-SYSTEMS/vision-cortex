## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that verifies and refreshes authorized connections to Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Create a Base44 backend function `googleConnectorSync` that reads stored OAuth credentials from Supabase for each Google service
- Validate each connector token by issuing a lightweight authenticated probe call (Drive: about.get, Calendar: calendarList.list, Gmail: users.getProfile, Sheets: spreadsheets metadata, Tasks: tasklists.list, Search Console: sites.list)
- For any token nearing expiry, invoke the refresh_token grant flow and persist updated tokens to Supabase
- Record connector status (connected/degraded/failed), last-checked timestamp, and scopes into a Base44 `ConnectorStatus` entity
- Emit a consolidated health report to CoreDocument and surface failures to the Discover layer intelligence feed
- Wire a Vercel Cron heartbeat to invoke `googleConnectorSync` on an hourly cadence for autonomous monitoring

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' in the ConnectorStatus entity with valid non-expired tokens, the health report is written to CoreDocument, and the Vercel Cron job successfully triggers the sync on schedule without auth errors.
