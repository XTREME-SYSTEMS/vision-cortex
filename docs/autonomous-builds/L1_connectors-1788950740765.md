## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes all authorized core connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `syncCoreConnectors` in Deno/TypeScript that iterates over each authorized Google service.
- For each connector, validate stored OAuth tokens and refresh expired access tokens using the stored refresh_token against Google's OAuth2 token endpoint.
- Ping a lightweight read endpoint per service (Drive files.list?pageSize=1, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists, Search Console sites.list) to confirm live connectivity.
- Persist connector status (connected/degraded/failed, last_checked, scopes, token_expiry) into a Base44 `ConnectorStatus` entity.
- Log the run into DeepRun with per-connector results for replayability.
- Expose results to the Discover layer so downstream intelligence functions can query connector availability before use.
- Emit a summary object and set an alert flag if any connector is failed or scopes are insufficient.

## Acceptance Criteria
Invoking syncCoreConnectors returns a status object listing all six connectors as 'connected' with valid non-expired tokens, a ConnectorStatus entity record is written per service with last_checked timestamp, live read pings return HTTP 200, and a DeepRun log entry records the run; any failed connector is flagged and surfaced in the response.
