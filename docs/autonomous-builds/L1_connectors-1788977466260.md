## Summary
Build a unified Google Workspace connector service that verifies and persists OAuth authorization status for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console into the Discover layer's data plane.

## Steps
- Create a Base44 backend function `googleConnectorSync` (Deno/TypeScript) that accepts a list of Google service scopes to verify
- Load stored OAuth credentials/tokens from Supabase secure store and refresh any expired access tokens using the Google token endpoint
- For each service (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) perform a lightweight authenticated ping (e.g. Drive about.get, Calendar calendarList, Gmail profile, Sheets metadata, Tasks tasklists.list, Search Console sites.list) to confirm live access
- Record per-service connection status, granted scopes, token expiry, and last-verified timestamp into a Base44 `GoogleConnector` entity
- Emit a consolidated health record and surface any missing scopes or failed services for re-authorization
- Register the function on Vercel Cron heartbeat for periodic re-validation to keep tokens fresh

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return a successful authenticated ping, each has a `GoogleConnector` entity record with status='connected', valid non-expired token, granted scopes, and a recent last-verified timestamp; any failed service is flagged for re-authorization and the cron re-validation runs without error.
