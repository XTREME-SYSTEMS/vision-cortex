## Summary
Build a unified Google Workspace connector health-check and sync orchestrator to verify and operationalize the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connectors.

## Steps
- Enumerate all authorized Google Workspace connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and load their stored OAuth credentials from Base44 entities
- Implement a per-connector health-check that validates token freshness, scopes, and performs a minimal read call against each Google API
- Add automatic OAuth token refresh logic for expired/near-expiry credentials and persist refreshed tokens back to the entity store
- Create a ConnectorStatus entity record capturing connector name, auth status, granted scopes, last successful call, and error detail
- Wire the orchestrator into the Discover layer so connected Google services feed the intelligence pipeline via a Vercel Cron heartbeat
- Log the full sync run to DeepRun for replayability and emit a consolidated status summary
- Surface a dashboard-consumable JSON summary of all six connectors' health

## Acceptance Criteria
All six connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) report auth_status='connected' with valid non-expired tokens, each passes a live minimal read call, a ConnectorStatus record with last_success timestamp exists per connector, the run is persisted to DeepRun, and the consolidated JSON summary returns zero failed connectors.
