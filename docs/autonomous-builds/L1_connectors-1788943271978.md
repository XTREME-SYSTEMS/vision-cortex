## Summary
Build a unified Google Workspace connector service that validates and manages OAuth connections for Drive, Calendar, Gmail, Sheets, Tasks, and Search Console.

## Steps
- Define a GoogleConnector Base44 entity tracking service name, OAuth scope, token status, refresh_token reference, last_validated timestamp, and health state
- Create backend function googleConnectorSync that iterates over the six services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) and verifies each OAuth token is valid
- For each service, perform a lightweight read probe (Drive: files.list limit 1; Calendar: calendarList; Gmail: profile; Sheets: spreadsheets metadata; Tasks: tasklists; Search Console: sites.list)
- Refresh expired access tokens using stored refresh_token and update token status in the GoogleConnector entity
- Persist validation results and health state to Supabase for zero-credit read access by the Discover layer
- Register the connector under the Discover layer data sources so intelligence gathering can consume Google services
- Add Vercel cron heartbeat to re-validate all six connectors every 6 hours and flag any degraded connection
- Emit a DeepRun execution log entry with per-service pass/fail results

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return a healthy validation status with valid non-expired tokens, GoogleConnector entities are persisted with last_validated timestamps, the cron heartbeat is scheduled, and a DeepRun log records six passing probes.
