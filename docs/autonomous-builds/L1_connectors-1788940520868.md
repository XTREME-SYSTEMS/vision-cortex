## Summary
Build a unified Google Workspace connector health-check and orchestration function that validates and registers all authorized Google service integrations (Drive, Calendar, Gmail, Sheets, Tasks, Search Console).

## Steps
- Create a Base44 backend function `googleConnectorOrchestrator` (Deno/TypeScript) that accepts a list of Google services to validate and register.
- For each service, retrieve OAuth credentials from the secure integration store and refresh access tokens if expired.
- Execute a lightweight read-only probe per service (Drive: files.list limit 1; Calendar: calendarList.list; Gmail: users.getProfile; Sheets: spreadsheets.get on a canary sheet; Tasks: tasklists.list; Search Console: sites.list).
- Record each connector's status, scopes granted, last-checked timestamp, and error (if any) into a Base44 `IntegrationConnector` entity.
- Emit a consolidated health report and write it to CoreDocument and Supabase for zero-credit audit access.
- Register a Vercel Cron heartbeat to re-run the orchestrator every 6 hours to detect token expiry or revoked scopes.
- Expose the aggregated connector status to the Discover layer so downstream state machines can gate on connector availability.

## Acceptance Criteria
All six Google services (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) return status 'connected' with valid non-expired tokens and required scopes; an IntegrationConnector record exists per service with a recent last-checked timestamp; the consolidated health report is persisted to CoreDocument/Supabase; and the Vercel Cron heartbeat is registered and successfully triggers a re-validation run.
