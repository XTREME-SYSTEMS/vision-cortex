## Summary
Build a unified Google Workspace connector health-check and sync orchestrator that validates and refreshes the authorized Drive, Calendar, Gmail, Sheets, Tasks, and Search Console connections for the Discover layer.

## Steps
- Enumerate the six authorized Google connectors (Drive, Calendar, Gmail, Sheets, Tasks, Search Console) from the integrations registry
- For each connector, verify OAuth token validity and refresh expired tokens via the Google Workspace auth flow
- Perform a minimal read probe per service (list Drive files, list Calendar events, list Gmail labels, read a Sheet range, list Tasks lists, fetch Search Console sites) to confirm live access
- Persist connector status (connected/expired/error), scopes, and last-checked timestamp to the ConnectorStatus Base44 entity
- Register a Vercel Cron heartbeat to re-run the health check every 6 hours for autonomous monitoring
- Emit a normalized capability manifest to CoreDocument so Discover-layer DEEP state machines can deterministically consume each connector
- Log the full run to DeepRun for replayability and surface any failures to the Council

## Acceptance Criteria
All six Google connectors return a 'connected' status with valid refreshed tokens and successful read probes, ConnectorStatus entities are updated with current timestamps, the capability manifest is written to CoreDocument, the cron heartbeat is registered, and a DeepRun log records the run with zero unresolved errors.
